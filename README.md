Мониторинг цен по регионам: Wildberries и Ozon.

## Как здесь работают

Задачи гоняются одной командой в Claude Code внутри VS Code.

1. Claude в чате Cowork пишет задачу в `prompts/ТЕКУЩИЙ.md`
2. Вы в IDE набираете `/rpm`
3. Дальше само: план → код → проверка → коммит → push → PR → мерж на зелёных

Ход работы копится в `prompts/РЕЗУЛЬТАТ.md`. Правила — `docs/правила-работы.md`.

С уточнением на один прогон:

```
/rpm только фазы 1-3, PR не открывай
```

Что делает `/rpm` по фазам:

| Фаза | Что происходит | Когда останавливается |
|---|---|---|
| 0. Подготовка | fetch, main, свежая ветка `task/*` | — |
| 1. План | читает репозиторий и промпт, пишет шаги и критерии готовности | — |
| 2. Код | реализует, коммитит мелкими кусками | — |
| 3. Проверка | **запускает и показывает вывод**, тесты, диф на секреты | если в дифе секрет — СТОП |
| 4. Сдача | коммит, push, `gh pr create`, squash-мерж | если фаза 3 не зелёная — PR остаётся открытым |

Мерж происходит сам только когда фаза 3 зелёная: запуск дал ожидаемый результат,
тесты прошли, секретов в дифе нет. Иначе PR висит и ждёт разбора.

# docs

Решения и требования по проекту. Заполняется до кода, а не после.

## Порядок

| Файл | Что содержит | Статус |
|---|---|---|
| `обратная-связь-клиента.md` | Дословно, что сказал клиент. Без интерпретаций. | ожидается |
| `требования.md` | Что из этого следует: что система обязана делать. | ожидается |
| `архитектура.md` | Как решили это построить и почему. | ожидается |
| `adr/` | Отдельные решения с последствиями. | ожидается |

## Правило

Требование, которого нет в `требования.md`, не реализуется.
Решение, которого нет в `adr/`, можно менять свободно.

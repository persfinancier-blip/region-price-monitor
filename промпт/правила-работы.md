# Правила работы — region-price-monitor

Прочитай это первым делом и работай по нему.

## Что за проект

Мониторинг цен Ozon и Wildberries по регионам. Поставка = продукт: запускать его будут другие
люди, не автор. Значит важна не «работает у меня», а воспроизводимость и честный отчёт о сбое.

Строим **парсер + preflight-слой достоверности**: перед прогоном проверяем, что условия
выполнены, и только потом собираем цены. Три проверяемых условия успеха, всё остальное — шум.

## Как ведём себя

1. **Делай, не спрашивай.** Уточняющий вопрос — только если без ответа можно сломать данные или
   пойти не туда на час. Всё остальное решай сам и скажи, что решил.
2. **Проверяй на живом коде.** Не «должно работать», а запустил и показал вывод. Утверждение без
   проверки хуже молчания.
3. **Коротко.** Результат и следующий шаг. Без пересказа того, что и так видно.
4. **Не трогай то, о чём не просили.** Особенно рабочие скрипты в `client_wb/`,
   `ozon_price_fetch/`, `wb_price_fetch/`.

## Матчасть — не переоткрывай заново

**Ozon**

- Публичного API нет. Цена берётся из **JSON виджета `webPrice`** внутри HTML (поле `cardPrice`).
- Общий поиск символа ₽ по странице — **баг**: цепляет чужие цены. Так не делать.
- Рабочий рецепт: без VPN + залогиненная сессия + прогрев с заходом на карточку + `curl_cffi`
  с профилем `edge`. Изюминка именно в залогиненной сессии.
- Куки живут ~24 часа. Регион **зашит в куку**, а не в параметр запроса. Схема — кука по
  умолчанию + опциональный прокси на город.
- Автономная сессия (Linux + Xvfb + Camoufox + мобильный IP) воспроизведена полностью и упирается
  в капчу на первом контакте. Это не техническая проблема, дальше решение нетехническое.
  Не пытайся «дожать» её кодом.

**Wildberries**

- API есть, в отличие от Ozon. Работаем через него.
- Одна сессия на всё, куки по городам не нужны.

**Эталон**

- Рабочий механизм — `test_pars_2` (venv лежит в `test_pars_work.zip`). Когда v2 «не работал»,
  причина была **в коде** — заменили `uc.Chrome` на Playwright и выкинули профиль `edge`, — а не
  в окружении. Прежде чем чинить окружение, сверься с эталоном.

## Архитектура — куда движемся

- **Логика в самостоятельных скриптах**, оболочка только принимает ввод и показывает вывод.
  Пайплайн в стиле Actions в панели. (ADR-0008)
- **Local-first**: Postgres опционален, рабочее состояние в плоских файлах. Источник и приёмник —
  локально либо БД с маппингом. Хранилища секретов нет. (ADR-0009)
- **Панель — рабочая точка ввода**, а не витрина. Приоритет интерактивным вкладкам в порядке:
  Города → Куки → Подключение → общий профиль.
- **Сбор кук**: логин один раз, дальше автообход городов. Кнопка симметрична: Ozon — кука на
  город, WB — одна сессия. Браузер локальный и видимый, серверный режим отложен.

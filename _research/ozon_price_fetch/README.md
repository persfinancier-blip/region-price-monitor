# ozon_price_fetch — цена Ozon без браузера

Запустил скрипт — получил цену. Браузер не открывается, вопросов не задаёт, окон не показывает.
Папка самодостаточная: копируй в любой проект, зависимость одна — `curl-cffi`.

```
ozon_price_fetch/
├── ozon_price.py          # ← рабочий механизм: один HTTP-запрос, цена на выходе
├── cookies_from_curl.py   # разовая подготовка cookies.json (вставил cURL из DevTools — готово)
├── example.py             # минимальный пример
├── requirements.txt
├── mobile_proxy.py        # мобильный прокси: поиск липкого мобильного IP, тоже без браузера
├── optional/
│   └── warm_cookies.py    # альтернативный способ добыть куки (открывает браузер). НЕ нужен
└── reference/             # оригиналы: test_pars_2, spike/check_ozon.py, слой ProxyProvider
```

## Мобильный прокси

`mobile_proxy.py` — та самая липкая сессия. Крутит `hold-session-session-<id>` в логине,
на каждой пробует оператора через `ipwho.is` и останавливается, когда выпал мобильный
(МТС/Билайн/МегаФон/Tele2/Yota). Оригинал гонял каждую пробу через Playwright — здесь
пробы идут обычным `curl_cffi`, окон не открывается.

```bash
# найти мобильный липкий IP и показать строку прокси
python mobile_proxy.py --proxy host:port:user:pass --tries 15

# найти и сразу снять цену через него
python mobile_proxy.py --proxy host:port:user:pass --sku 1964684436 --cookies cookies/ozon/msk.json

# то же самое одной командой из основного скрипта
python ozon_price.py 1964684436 --cookies cookies/ozon/msk.json \
    --proxy host:port:user:pass --find-mobile
```

Из кода:

```python
from mobile_proxy import find_mobile_session
from ozon_price import fetch_price

proxy = find_mobile_session("host:port:user:pass", tries=15)
r = fetch_price("1964684436", cookie_file="cookies/ozon/msk.json", proxy=proxy)
```

Ozon режет прокси по репутации IP: датацентровые и резидентные метит как VPN или кидает
капчу, мобильные почти не трогает. Но куки всё равно нужны — снимай их через тот же прокси,
иначе IP не совпадёт и прилетит 403.

В `reference/` лежат оригиналы: `spike__check_ozon__mobile_proxy.py` (браузерный вариант
перебора), плюс слой `ProxyProvider` из основного проекта — `app_proxy__static.py`
(карта регион→прокси), `app_proxy__health.py` (cooldown после банов), `adr-0003-proxy-provider.md`.

## Механизм

```
GET https://www.ozon.ru/api/entrypoint-api.bx/page/json/v2?url=/product/<sku>/
    cookies: из cookies/ozon/<region>.json
    headers: x-o3-app-name: dweb_client + x-o3-app-version + x-o3-manifest-version
    curl_cffi impersonate="chrome"          ← без него 403: Ozon фингерпринтит TLS/JA3
    proxies: опционально
→ JSON с widgetStates → виджет webPrice → price / cardPrice / originalPrice
```

Транспорт — ровно тот, что в `C:\Dev\test_pars_2\ozon_parser.py`. Он честно ходил без браузера
и отдавал HTTP 200.

## ⚠️ Что в эталоне было сломано

Эталон брал **первый попавшийся** ключ `webPrice`/`webSale` из `widgetStates`. Но в ответе
PDP живут ещё и карусели рекомендаций со своими `webPrice` — то есть цены чужих товаров.
Его собственные выгрузки это и показывают, один и тот же sku 1964684436:

| Файл | Цена |
|---|---|
| ozon_msk_20260725_140831.csv | 209 ₽ |
| ozon_msk_20260725_182214.csv | 2805 ₽ |
| ozon_nvs_20260725_182300.csv | 9446 ₽ |
| ozon_msk_20260726_045819.csv | 188 ₽ |

Разброс в 45 раз за сутки — это не динамическое ценообразование, это чужие цены.

Здесь виджет цены ищется через `layout` (там указан `stateId` именно товарного блока),
а не перебором. Если `layout` в ответе нет и кандидатов несколько с разными ценами —
поднимается `AmbiguousPrice` вместо тихого «взял первый». Плюс сверяется `pageInfo.url`
с запрошенным sku, чтобы поймать редирект на другую карточку.

В поле `trusted` видно, как опознан виджет: `True` — через `layout`, `False` — единственный
кандидат без подтверждения (стоит перепроверить глазами).

## Какие куки нужны

В эталоне куки были **гостевые, без логина**: в `cookies/ozon/msk.json` лежит
`__Secure-user-id = "0"`, а в `nvs.json` ещё и `guest = "true"`.
`__Secure-access-token` / `__Secure-refresh-token` там есть, но это анонимные сессионные
токены, которые Ozon выдаёт любому гостю (даже не JWT). То есть залогиненный аккаунт для
чтения цены не требовался.

Снимались они дампом всего Playwright-профиля (`context.cookies()` без фильтра по домену),
поэтому в файл заодно попали куки Wildberries (`x_wbaas_token`) и Яндекса (`yandexuid`) —
для Ozon они бесполезны, но и не мешают.

### Где в куках регион

Локально — нигде. `msk.json` и `nvs.json` отличаются ровно тремя значениями:
`__Secure-access-token`, `__Secure-refresh-token`, `xcid` — это идентичность сессии.
Выбранный город Ozon держит **у себя**, привязанным к этой сессии. Поэтому:

* один файл кук = один город, и подменой строчки в файле город не переключить;
* два города — это две отдельные сессии, снятые по очереди (или в разных профилях браузера);
* кука `ADDRESSBOOKBAR_WEB_CLARIFICATION` регион НЕ несёт: `1784976022` — это просто
  отметка времени (25.07.2026 10:40), когда закрыли всплывашку с адресом.

Убедиться, что файл несёт нужный город, можно только по ответу Ozon:

```bash
python ozon_price.py <sku> --cookies cookies/ozon/nvs.json --show-region
```

Он покажет адресные и доставочные виджеты из ответа — там видно город и сроки.

## Как снять куки — единственное место, где нужен твой браузер

Куки снимаются **руками один раз** (и потом раз в ~сутки), обычным копипастом. Скрипт при этом
ничего не открывает. Пример для Новосибирска:

1. Открой **новое окно в режиме инкогнито** — так сессия чистая и не собьёт твой основной вход.
2. Зайди на ozon.ru → селектор города слева сверху → **Новосибирск**. Надёжнее выбрать
   конкретный пункт выдачи в этом городе: тогда Ozon точно привяжет регион к сессии.
3. Открой любую карточку товара и дождись, пока прогрузится цена. Этот шаг обязателен —
   без захода на карточку сессия часто остаётся «непрогретой».
4. F12 → вкладка **Network** → в фильтр вбей `entrypoint-api` → кликни любой такой запрос →
   правый клик → **Copy → Copy as cURL (bash)**.
5. `python cookies_from_curl.py --out cookies/ozon/nvs.json` → вставить → Ctrl+Z, Enter
   (на Windows; на Linux/Mac — Ctrl+D).
6. Проверить город: `python ozon_price.py <sku> --cookies cookies/ozon/nvs.json --show-region`
7. Проверить цену: `python ozon_price.py <sku> --cookies cookies/ozon/nvs.json`

Для второго города — **новое окно инкогнито** и всё заново. В одном окне не получится:
сессия одна, выбор Новосибирска затрёт Москву, и оба файла будут про Новосибирск.

В `optional/warm_cookies.py` лежит второй способ — через Playwright: он сам откроет браузер,
подождёт, пока выберешь город, и сохранит куки. Нужен, только если копипаст неудобен;
там та же логика и те же требования.

В файле кук есть `__Secure-access-token` / `__Secure-refresh-token` — держи его вне git.

## Правила, которые нельзя нарушать

| Правило | Почему |
|---|---|
| Читать с того же IP, где снимались куки | Куки привязаны к сессии/IP; с чужого → 403 |
| Один файл кук = один город | Регион живёт в куке |
| Не искать цену общим поиском по `₽` | Ловит цены из блока рекомендаций и молча отдаёт чужое число. Источник истины — виджет `webPrice` |
| Держать вежливый темп (`pause`) | Иначе быстро прилетит антибот |

## Про прокси

Прокси **не заменяет куки**. По спайк-отчёту от 22.07.2026: голый HTTP-запрос через мобильный
прокси (МегаФон, Мурманск) без кук → **403**. Работала связка «куки + curl_cffi», прокси — опция.

Мобильные IP (МТС/Билайн/МегаФон/Tele2/Yota) Ozon почти не трогает, а датацентровые и резидентные
метит как VPN или кидает капчу. Так что мобильный прокси помогает — но как подложка под куки,
а не вместо них. Используешь прокси — снимай куки в браузере через тот же прокси, иначе IP не совпадёт.

Формат принимается любой: `host:port:user:pass`, `host:port`, `http://user:pass@host:port`.
Липкая сессия (`hold-session-session-<id>`) живёт внутри логина и трогать её не нужно.

## Если сломалось

| Симптом | Что делать |
|---|---|
| `CookiesExpired`, 403 | Пересобрать куки. Проверить, что IP тот же (VPN выключен) |
| `OzonError`, HTTP 400 | Протухли `x-o3-app-version` / `x-o3-manifest-version` — обновить из свежего cURL в `O3_HEADERS` |
| `PriceNotFound`, виджеты есть | Ozon сменил разметку — посмотреть список виджетов в тексте ошибки |
| Все стратегии — сетевая ошибка | Прокси моргает; проверить канал |

`DEFAULT_IMPERSONATE` — перебор профилей TLS от свежего к старым. Обновится `curl_cffi` —
добавь новые версии Chrome в начало списка.

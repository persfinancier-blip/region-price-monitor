# Парсер цен WB / Ozon (по регионам)

Мониторинг цен Wildberries и Ozon по нескольким регионам РФ. Источник и приёмник — плоские файлы (CSV) или PostgreSQL.

## Как это работает

Ozon защищён антиботом, поэтому работа делится на два этапа:

**1. Прогрев (ДЕСКТОП, с экраном).** В видимом браузере вы логинитесь в Ozon и выбираете точку получения по каждому региону. Сохраняются куки (`profiles/ozon_<код>/cookies.json`). Залогиненную сессию Ozon не гоняет через капчу — это и даёт стабильность.

**2. Сбор (СЕРВЕР или десктоп, headless).** По сохранённым кукам цены Ozon берутся тихим HTTP-запросом (`curl_cffi`, TLS-профиль edge) прямо из страницы товара — без браузера. WB собирается прямым API. Результат — в CSV и/или PostgreSQL.

> Требования к сети: чистый российский IP **без VPN** (Ozon блокирует VPN/дата-центр на сетевом уровне). Куки Ozon живут ~сутки — периодически нужен новый прогрев на десктопе.

## Установка

### Windows (десктоп — прогрев + сбор)
Дважды кликните **`install.bat`** — создаст venv, поставит зависимости, скопирует config.
Затем запускайте **`run_parser.bat`**.

### Linux (сервер — только сбор)
```bash
./server_run.sh            # создаст venv, поставит ядро, запустит сбор
```
Прогрев на сервере не делается: скопируйте папку `profiles/` с десктопа, где вы прогрели куки.

## Порядок работы (десктоп, `run_parser.bat`)

Меню ведёт по шагам:

1. **Откуда берём SKU** — файл (CSV/Excel: `marketplace,sku`) или PostgreSQL (`parser_skus`).
2. **Куда сохраняем результат** — папка (CSV), PostgreSQL или оба.
3. **Создаём регионы** — на каждый регион: вход в Ozon + выбор ПВЗ (это и создаёт профиль) и выбор региона на WB (определяется `dest`). Регион = профиль Ozon + `dest` WB.
4. **Парсинг** — Ozon скрытым `curl_cffi`, что уйдёт в 403 — открывается браузер (решаете капчу); WB через API. Результат сохраняется по шагу 2.

Ничего не захардкожено: SKU и регионы берутся только из выбранных источников.

## PostgreSQL

Задайте подключение в `.env` (см. `.env.example`) — сервер прочитает его сам:
```
RPM_PG_HOST=... RPM_PG_PORT=5432 RPM_PG_DB=parser RPM_PG_USER=... RPM_PG_PASSWORD=...
```
Таблицы создаются автоматически: `parser_skus` (SKU-источник), `parser_results` (результаты).
Без переменных PG сбор пишет в CSV (`results/`).

## Файлы

| Файл | Назначение |
|---|---|
| `cli.py` | Интерактивное меню (десктоп): источник SKU → вывод → профили → регионы → парсинг |
| `collect.py` | Сбор цен (headless) — сервер |
| `ozon.py` | Ozon: скрытый `curl_cffi/edge` + разбор цены из виджета `webPrice` |
| `wb.py` | WB: прямой batch-API |
| `db.py` | PostgreSQL (источник SKU + приёмник результатов) |
| `config.json` | Регионы (код, название, `wb_dest`) |
| `products.json` / `sku.csv` | Список SKU (если не из PG) |

## Цена Ozon

Берётся строго из виджета цены запрошенного товара (не из рекомендаций):
`price` — по Ozon-карте (основная), плюс `price_regular` (обычная) и `price_original` (зачёркнутая).

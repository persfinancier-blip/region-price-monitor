# G01 / SG04 / PR01 / ST01 / T01 / C27.I01

## Goal
Prove that one fresh Russian mobile sticky proxy session can bootstrap an Ozon browser session and hand the complete browser cookie jar to a lightweight HTTP client without changing proxy egress or browser/TLS identity.

## Contract
1. Select one fresh mobile `hold-session-session-<id>` proxy identity.
2. Reuse that exact bound proxy identity in Camoufox.
3. Verify browser public IP equals the selected proxy public IP.
4. Capture the browser's real TLS/HTTP2 fingerprint on a neutral fingerprint endpoint.
5. Capture the complete browser cookie jar from the browser context; do not flatten cookie names and preserve domain/path scope in memory.
6. Capture the browser's real User-Agent and browser family.
7. Create one `curl_cffi.Session` using the same browser family target (`firefox` for Camoufox/Firefox), the exact browser User-Agent, the complete cookie jar, and the exact same bound sticky proxy identity.
8. Verify curl public IP equals both the selected IP and browser IP.
9. Capture curl's TLS/HTTP2 fingerprint through the same neutral endpoint and compare `ja3_hash`, `ja4`, and `akamai_hash` where present.
10. Fail closed before Ozon if the compared browser and curl fingerprints differ.
11. Attempt Ozon price retrieval through `entrypoint-api` then `composer-api` without rotating to a different browser family.
12. Parse only the exact requested SKU price contract already used by `parser/core/ozon.py`.

## Acceptance
PASS only when:
- selected proxy IP == browser IP == curl IP;
- complete named browser cookie jar was transferred;
- browser family and curl TLS impersonation family match;
- neutral TLS/HTTP2 fingerprints match for all compared fields;
- exact requested SKU price is returned.

Gate: `OZON_SESSION_COHERENCE_PRICE_PROVEN`.

## Failure semantics
- Mobile proxy selection failure: explicit blocked gate.
- Browser IP mismatch: `OZON_C27_BROWSER_STICKY_IP_MISMATCH`.
- Unsupported browser family: explicit fail-closed result.
- Curl IP mismatch: `OZON_C27_CURL_STICKY_IP_MISMATCH`.
- TLS/HTTP2 fingerprint mismatch: `OZON_C27_TLS_FINGERPRINT_MISMATCH`.
- Ozon challenge/no exact price: `OZON_SESSION_COHERENCE_NO_PRICE`.

## Security / evidence
- Proxy credentials stay memory-only.
- Cookie values stay memory-only and are never persisted or printed.
- Only cookie counts, browser family/version, public IP evidence, neutral fingerprint hashes, endpoint result, and price are printed.
- No CAPTCHA submission, pointer automation, drag automation, or challenge-result endpoint is used.

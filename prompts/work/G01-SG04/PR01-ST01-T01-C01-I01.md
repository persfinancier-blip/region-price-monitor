# G01.SG04.PR01.ST01.T01.C01.I01

## Role
Execute only the evidence-capture Task for current Ozon fresh-session regional behavior. Do not implement the final parser/collector.

## Goal
Starting from no manually warmed Ozon profile/cookie file, capture sanitized current Ozon behavior through accepted SG02 ProxyContext for representative SKU/city cases.

## Inputs
- current repository `main` code (`ozon.py`, `warm_browser.py`, collector paths);
- accepted SG01 CityRecord and SG02 transport contracts;
- representative Ozon SKU(s) and runtime city proxy configuration available to the executor.

## Actions
1. Start from fresh in-memory/session state; do not load legacy `cookies.json`.
2. Route every network call through the selected city ProxyContext.
3. Probe homepage/product flow sufficiently to observe successful or blocked session behavior.
4. Capture only sanitized response/session facts needed to answer:
   - which automatically issued cookies/headers/state are needed;
   - what regional/location/delivery-context signals are observable;
   - whether requested city can be verified;
   - what anti-bot/session failure forms occur.
5. Record exact evidence paths/hashes/HTTP outcomes without credentials, tokens or raw authenticated proxy URI.

## Output Contract
Either:
- sanitized evidence bundle sufficient for PR01.ST02 to define bootstrap + city verification; or
- `OZON_CONTEXT_CONTRACT_UNPROVEN` with exact missing evidence.

## Acceptance
- no legacy cookie/profile prerequisite;
- all calls use ProxyContext;
- no manual login/PVZ selection/browser action;
- no assumption that proxy IP alone proves Ozon effective city;
- secrets excluded from committed evidence.

## Failure Boundary
Do not implement final bootstrap, parser, collector, fallback, persistence or scheduler. Do not add new mandatory CityRecord fields.

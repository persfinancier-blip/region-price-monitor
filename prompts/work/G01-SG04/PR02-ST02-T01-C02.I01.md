# G01.SG04.PR02.ST02.T01.C02.I01

## Role
Implement and prove automatic requested-city verification plus bounded context refresh/rebootstrap across the accepted autonomous engine strategy.

## Goal
Ensure an OzonContext cannot yield a successful regional price unless its effective context matches the requested city, and ensure repeated runs need no human browser action even when hidden Selenium/Chrome participates.

## Inputs
- accepted OzonContext from PR02.ST01 C02;
- accepted PR01 C02 city-verification rule;
- SG02 ProxyContext authority.

## Actions
1. Evaluate the exact evidenced region/context signal against requested `city`.
2. Mark context verified, mismatched or unproven; never coerce unproven to success.
3. Implement bounded automatic refresh/rebootstrap using the accepted engine strategy.
4. Keep every refresh/rebootstrap on the same CityRecord ProxyContext, including any hidden browser instance.
5. Never migrate silently to direct networking, another city, visible/manual browser flow or SG05 legacy fallback.
6. If a challenge requires human action, return a typed autonomous-path failure; do not wait for user input.
7. Bound retries and ensure temporary browser processes/state are cleaned up.
8. Expose engine provenance and typed safe status for caller/collector without secrets.

## Output Contract
Verified city-bound OzonContext or typed `context_mismatch`, `context_unproven`, `browser_proxy_binding_unproven`, transport/session/anti-bot/bootstrap failure.

## Acceptance
- wrong/unverified city cannot yield success;
- repeated execution can recreate/refresh state with zero human interaction;
- hidden Selenium/Chrome remains allowed as autonomous engine;
- bounded retries/process lifetime;
- no direct or manual fallback;
- diagnostics secret-free.

## Failure Boundary
Do not weaken PR01 evidence criteria; no price parser changes, persistence, scheduler or SG05 manual fallback changes.

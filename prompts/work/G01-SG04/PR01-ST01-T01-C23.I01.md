# Immutable Prompt — G01.SG04.PR01.ST01.T01.C23.I01

## Goal
Replace the time-separated C18 -> C19 -> C22 runtime dependency with one continuous operator run that selects a fresh Russian mobile sticky proxy session, immediately obtains the Ozon zero-cookie challenge through that exact ProxyContext, decodes the embedded background/puzzle URLs, fetches both images through the same ProxyContext, and runs the repository-owned local solver.

C23 is a solve-analysis cycle only. It must not submit a CAPTCHA answer or mutate Ozon challenge state.

## Input Contract
- One visible runtime proxy string: `host:port:user:pass` (or explicit scheme form).
- Optional Ozon SKU; default may reuse the accepted reference SKU.
- Existing repository-owned components:
  - `tools/mobile_proxy.py` sticky mobile selector;
  - reference Ozon entrypoint request contract;
  - `parser/core/captcha/ozon_payload.py`;
  - `parser/core/captcha/slider.py`.

## Runtime Contract
The entire network contour MUST execute in one Python process and one operator invocation:

`proxy credentials -> fresh sticky session selection -> immediate same-session neutral recheck -> Ozon entrypoint challenge -> captchaURL decode -> exact background/puzzle fetch -> local solver`

No accepted IP/session from a previous run may be required.

## Implementation Contract
1. Ask for proxy credentials exactly once.
2. Use the existing `find_mobile_proxy()` selector to rotate to a currently accepted Russian mobile operator and obtain a fresh `session_id` + public IP.
3. Rebuild exactly that selected sticky session from the same input credentials and immediately recheck the neutral public IP.
4. Compare only against the IP selected seconds earlier in THIS run. Do not read C18 SAFE report or depend on historical expected IP.
5. Call the accepted zero-cookie Ozon entrypoint sequence through that same ProxyContext. No Ozon home warmup, browser, cookies, manual login or profile.
6. Stop on a live challenge JSON carrying `captchaURL`; keep the full URL memory-only and raw challenge only under Git-ignored local probe evidence.
7. Decode the embedded payload with `decode_captcha_url()` and recover exact `is` background and `ps` puzzle URLs in memory.
8. Fetch both image bytes through the SAME selected ProxyContext, validate with Pillow, persist raw bytes only under Git-ignored local evidence.
9. Run `solve_piece_by_contour(piece, background)` and emit structured x/y/score/confidence/error.
10. If selector, continuity, challenge acquisition, payload decode, image fetch, image validation or solver confidence fails, stop with a typed gate. Never fabricate coordinates.
11. Do not submit `/abt/captcha/result`, do not emulate pointer trajectories, do not mutate challenge cookies/state, and do not claim restored Ozon entrypoint access.
12. No Selenium/Playwright/browser, external CAPTCHA solver API, Docker or managed unlocker in C23.
13. Never persist proxy credentials, full challenge URL, cp token or full image URLs in SAFE report.

## Output Contract
- `tools/probe_ozon_single_run_c23.py`
- `tests/test_wave2_ozon_single_run_c23.py`
- `tests/RUN_OZON_SINGLE_RUN_C23.bat`
- SAFE report `parser/core/local/probes/ozon_single_run_c23_report.json`
- raw challenge/images only under `parser/core/local/probes/ozon_single_run_c23/`.

## Acceptance Criteria
Deterministic:
- challenge URL extraction accepts only non-empty string `captchaURL`;
- source audit proves C23 has no dependency on historical C18/C19 report files;
- source audit proves no challenge submission endpoint/trajectory automation;
- report construction contains no proxy password/full challenge/image URLs.

Live success gate:
- `OZON_SINGLE_RUN_CHALLENGE_IMAGES_SOLVED_LOCAL` — fresh mobile sticky selected, immediate continuity confirmed, live challenge obtained, exact two images fetched/validated, repository-owned solver returns `ok=true`.

Other valid gates include:
- `OZON_SINGLE_RUN_MOBILE_PROXY_NOT_SELECTED`;
- `OZON_SINGLE_RUN_STICKY_IP_MISMATCH`;
- `OZON_SINGLE_RUN_CHALLENGE_NOT_OBTAINED`;
- `OZON_SINGLE_RUN_CHALLENGE_PAYLOAD_INVALID`;
- `OZON_SINGLE_RUN_IMAGE_FETCH_FAILED`;

- `OZON_SINGLE_RUN_SOLVER_UNCERTAIN`.

## Evidence
- deterministic test output;
- SAFE report;
- raw local challenge/background/puzzle evidence under Git-ignored local path.

## Failure Conditions
- dependence on a historical C18 expected IP or old session id;
- separate operator runs required between selection/challenge/solve;
- challenge answer submission or pointer automation;
- browser/external solver dependency;
- credentials or full signed URLs persisted;
- solver uncertainty represented as success.

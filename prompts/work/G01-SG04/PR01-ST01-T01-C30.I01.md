# G01 / SG04 / PR01 / ST01 / T01 / C30.I01

## Goal
Determine whether Ozon bootstrap quality varies primarily by fresh mobile sticky session/egress while keeping the browser network stack constant.

## Contract
1. Load the test proxy from the existing gitignored local proxy file.
2. For each bounded attempt, derive a fresh `hold-session-session-<id>` from the same proxy account.
3. Prove the public egress IP for that bound sticky session.
4. Start Camoufox on that exact bound proxy identity and require browser IP == selected IP.
5. Open Ozon without interacting with any challenge.
6. Observe the complete browser cookie jar in memory and record names/count only.
7. Explicitly observe whether `__Secure-ext_xcid` is present.
8. From the same Camoufox page/context, call Ozon entrypoint then composer with browser-native `fetch()` and `credentials: include`.
9. Parse only the exact requested SKU using the existing strict parser.
10. Stop on the first exact price; otherwise summarize all bounded attempts.

## Acceptance
PASS only when a fresh sticky attempt preserves one IP into Camoufox and browser-native Ozon API returns the exact requested SKU price.

Gate: `OZON_C30_FRESH_STICKY_PRICE_PROVEN`.

## Diagnostic value
The successful historical standalone probe had a larger cookie set including `__Secure-ext_xcid` and returned HTTP 200 + price, while C28/C29 produced only `__Secure-ETC` + `abt_data` and returned 403 challenge. C30 tests whether that state tracks the fresh sticky/egress while browser behavior remains constant.

## Security / evidence
- Proxy credentials remain in the existing gitignored local file/in memory only.
- Cookie values are never printed or persisted.
- No CAPTCHA submission, drag/pointer automation, or challenge-result endpoint is used.

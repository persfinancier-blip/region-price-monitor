# G01 / SG04 / PR01 / ST01 / T01 / C35.I01

## Goal
Determine whether the current Ozon browser bootstrap failure is specific to Camoufox or reproduces in an ordinary Playwright Firefox browser on the same exact sticky mobile proxy session.

## Contract
1. Load the cached local proxy credential from `parser/core/local/ozon_test_proxy.txt`.
2. Create exactly one fresh `hold-session-session-<id>` identity for the live comparison.
3. Prove the sticky public IP before the browser comparison.
4. Run ordinary Playwright Firefox first on the exact sticky proxy.
5. Run Camoufox second on the same exact sticky proxy without changing session id or egress.
6. For each browser, navigate only to Ozon home and observe:
   - main HTTP status;
   - final URL;
   - `window.isSecureContext`;
   - cookie count and cookie names;
   - presence of `__Secure-ext_xcid`;
   - challenge markers;
   - TLS security details when available.
7. Re-prove the sticky IP after both browser runs.

## Acceptance / evidence
This checkpoint is diagnostic and does not claim Ozon access restored.

- `OZON_C35_STOCK_FIREFOX_DIFFERS_FROM_CAMOUFOX` when stock Firefox and Camoufox materially differ in status/challenge/session bootstrap on the same sticky.
- `OZON_C35_BROWSERS_MATCH` when both show the same bootstrap outcome.
- Explicit fail-closed gate when stock Playwright Firefox is unavailable locally.

## Safety
- No CAPTCHA submission or interaction.
- No pointer/drag automation.
- No challenge-result endpoint.
- No stealth/fingerprint tuning of stock Firefox.
- Proxy credentials and cookie values remain local/memory-only.

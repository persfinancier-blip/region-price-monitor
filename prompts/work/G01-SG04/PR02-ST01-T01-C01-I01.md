# G01.SG04.PR02.ST01.T01.C01.I01

## Role
Implement only automatic fresh Ozon session/bootstrap state using the accepted SG02 transport and PR01 contract.

## Goal
Create a reusable in-memory `OzonContext` for one CityRecord without loading a manually prepared profile/cookie file.

## Inputs
- accepted PR01 bootstrap contract;
- CityRecord;
- accepted SG02 ProxyContext + curl_cffi adapter.

## Actions
1. Create fresh Ozon session state via the accepted curl_cffi adapter.
2. Execute every bootstrap/home/product prerequisite call through the supplied ProxyContext.
3. Capture only automatically issued session/cookie state permitted by PR01.
4. Return typed success/failure without raw secret-bearing exception/log output.
5. Preserve caller city identity separately from mutable session state.

## Output Contract
`OzonContext` with safe city identity, automatically created session state and bootstrap status, or explicit transport/session/bootstrap failure.

## Acceptance
- no `ozon_profile_dir`, `cookies.json`, Selenium/Chrome or manual interaction;
- no direct-network fallback when ProxyContext supplied;
- cookies/session state may be automatic, not human-maintained;
- bounded timeouts/retries;
- secrets absent from ordinary diagnostics.

## Failure Boundary
Do not decide city verification semantics beyond PR01, do not parse price, modify collector, fallback, persistence or scheduler.

# G01.SG04.PR03.ST02.T01.C02.I01

## Role
Classify Ozon outcomes for the repaired autonomous C02 context engine without collapsing engine-specific failures into generic HTTP status.

## Goal
Give each requested Ozon SKU/city one explicit success or failure while preserving engine provenance and requested-city identity.

## Inputs
- accepted verified C02 OzonContext state;
- SG02 TransportOutcome where applicable;
- hidden-browser engine outcome where applicable;
- PR03.ST01 parser output.

## Actions
1. Classify success only when requested-city context is verified and price parser succeeds.
2. Distinguish proxy/auth/connect/timeout/HTTP failures from hidden-browser startup/proxy-binding/navigation/lifecycle failures.
3. Distinguish context mismatch/unproven, anti-bot/session rejection, product/no-price/malformed content and unexpected parser failure.
4. Preserve requested SKU, city and safe engine provenance on every outcome.
5. Redact proxy/session/browser secrets and do not return a broad synthetic `403` for unrelated failures.

## Output Contract
Typed per-SKU Ozon outcome covering success and all accepted C02 transport/browser/context/session/semantic failure classes.

## Acceptance
- `200_no_price` is semantic, not proxy failure;
- browser proxy-binding failure is explicit;
- human-action-required challenge is explicit autonomous failure, not a waiting state;
- no failure appears as a valid empty/zero price;
- engine implementation detail does not change price semantics.

## Failure Boundary
No context bootstrap redesign, collector policy, persistence, scheduler or SG05 manual fallback changes.

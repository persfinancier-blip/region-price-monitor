# G01.SG04.PR01.ST01.T01 — C15.I01

## Input Contract
- One Ozon SKU.
- One existing anonymous/guest Ozon cookie JSON file from the recovered working lineage or an equivalent fresh guest cookie export.
- One city label + one explicit-scheme SG02 ProxyContext.
- No browser, no login, no PVZ selection, no second city and no regional comparison.

## Goal
Stop testing invented Ozon bootstrap/page-loading paths and reproduce the recovered working reader mechanism as directly as possible while preserving SG02 ProxyContext as the sole routing/auth authority.

Recovered reference mechanism:
`guest cookies + x-o3-* dweb headers + curl_cffi impersonate -> GET https://www.ozon.ru/api/entrypoint-api.bx/page/json/v2?url=/product/<sku>/ -> JSON widgetStates`.

The probe MUST NOT warm `https://www.ozon.ru/` and MUST NOT fetch product HTML before the entrypoint request.

## Actions
1. Load the supplied cookie JSON without modifying it.
2. Build exactly one ProxyContext from operator input; do not construct credential-bearing proxy URLs in the reader.
3. Prove neutral egress through the same ProxyContext.
4. Call the entrypoint directly using the recovered dweb headers and the reference impersonation sequence: `chrome`, `chrome146`, `chrome145`, `chrome142`, `chrome136`.
5. Stop on the first HTTP 200 JSON response that contains normal product state rather than challenge JSON.
6. Bind the response to the requested SKU when `pageInfo.url` is present.
7. Select the product price via `layout -> stateId -> widgetStates`; never take the first `webPrice` globally. If layout is absent and multiple conflicting price candidates exist, fail closed as ambiguous.
8. Persist raw response bodies only under the existing Git-ignored local probes directory. SAFE REPORT must never contain cookie values or proxy credentials.

## Output Contract
SAFE REPORT includes:
- neutral egress identity;
- cookie file SHA/count only;
- each attempted impersonation + HTTP status + JSON/challenge classification;
- exact SKU binding result;
- exact price parse result including trusted/layout-bound status;
- final typed evidence gate.

## Acceptance
`OZON_REFERENCE_ENTRYPOINT_DATA_ACCESS_PROVEN` only when one reference impersonation returns HTTP 200 normal JSON, requested SKU binding passes, and the price parser identifies a product price without ambiguity.

## Failure Conditions
- `OZON_REFERENCE_COOKIES_REJECTED`: all usable attempts are 401/403 or challenge responses.
- `OZON_REFERENCE_O3_HEADERS_STALE`: HTTP 400 dominates the reference attempts.
- `OZON_REFERENCE_PRODUCT_BINDING_FAILED`.
- `OZON_REFERENCE_PRICE_AMBIGUOUS`.
- `OZON_REFERENCE_PRICE_NOT_FOUND`.
- `OZON_REFERENCE_TRANSPORT_FAILED`.

C11-C14 remain immutable diagnostic history and are superseded for the current reader proof. No production reader replacement is accepted until this C15 live probe succeeds.

# G01.SG04.PR01.ST01.T01 — C16.I01

## Input Contract
- One explicit-scheme mobile proxy gateway.
- One proxy username and password.
- Up to 15 sticky-session attempts.
- No Ozon cookies required.

## Goal
Reproduce the recovered Claude `mobile_proxy.py` behavior before any further Ozon-access experimentation:

`rotate hold-session-session-<id> -> curl_cffi identity/operator check -> stop when a known RU mobile operator is selected`.

This cycle proves only the sticky mobile proxy selector. It does not claim Ozon data access.

## Actions
1. Accept bare, `-hold-session`, `-hold-session-session`, or already session-bound usernames and normalize each attempt to exactly one `-hold-session-session-<id>` suffix.
2. Generate a fresh sticky session id for each attempt.
3. Route the neutral identity request through SG02 `ProxyContext` using `curl_cffi`; no Playwright/browser.
4. Require `mobile == true` and identify one of the recovered accepted operator families: MTS, Beeline/VimpelCom, MegaFon, Tele2/T2, Yota/Scartel.
5. Stop on the first accepted attempt.
6. Persist only public egress metadata and generated session id. Never persist proxy credentials.

## Output Contract
SAFE REPORT:
- number of attempts;
- per-attempt public IP/location/mobile flag;
- ISP/operator evidence fields returned by the neutral identity service;
- generated sticky session id;
- selected operator/session when successful;
- no proxy username/password.

## Acceptance
`OZON_STICKY_MOBILE_OPERATOR_SELECTED` only when an attempt has successful transport, `mobile=true`, and a known mobile operator is evidenced.

Typed non-acceptance:
- `OZON_MOBILE_FLAG_SEEN_OPERATOR_UNPROVEN`
- `OZON_STICKY_MOBILE_OPERATOR_NOT_FOUND`
- `OZON_STICKY_PROXY_TRANSPORT_FAILED`

## Runner
Windows: `tests/RUN_OZON_MOBILE_PROXY_C16.bat`
Safe report: `parser/core/local/probes/ozon_mobile_proxy_selector_report.json`

No Ozon page, entrypoint, cookies, browser, region comparison, or price parsing belongs in C16.

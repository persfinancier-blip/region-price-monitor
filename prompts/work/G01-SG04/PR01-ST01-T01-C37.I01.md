# G01 / SG04 / PR01 / ST01 / T01 / C37.I01

## Goal
Determine whether Ozon bootstrap quality changes when the exact same stock Playwright Firefox profile is persisted across sequential browser launches on one exact sticky mobile proxy session.

## Contract
1. Load the cached local proxy credential from `parser/core/local/ozon_test_proxy.txt`.
2. Create one fresh `hold-session-session-<id>` identity and keep it unchanged for the full checkpoint.
3. Prove the sticky public IP before run 1, between runs, and after the final run.
4. Use stock Playwright Firefox only; no Camoufox in this checkpoint.
5. Use `firefox.launch_persistent_context()` with one gitignored local profile directory under `parser/core/local/profiles/`.
6. Reopen that same persistent profile for three sequential runs on the exact same sticky proxy/IP.
7. For each run observe only:
   - main HTTP status;
   - final URL;
   - `window.isSecureContext`;
   - full cookie count and cookie names;
   - presence of `__Secure-ext_xcid`;
   - challenge markers;
   - TLS details when available.
8. Persist browser profile state locally, but never persist proxy credentials or cookie values in GitHub/evidence.

## Acceptance / evidence
Diagnostic only; this checkpoint does not claim Ozon access restored.

- `OZON_C37_PERSISTENT_PROFILE_IMPROVED` when a later run materially improves session bootstrap relative to run 1 (more cookies, `__Secure-ext_xcid`, or non-challenge HTTP outcome).
- `OZON_C37_PERSISTENT_PROFILE_NO_IMPROVEMENT` when all sequential runs remain materially equivalent.
- Explicit fail-closed gate on sticky-IP drift or browser/profile failure.

## Safety
- No CAPTCHA submission or interaction.
- No pointer/drag automation.
- No challenge-result endpoint.
- No browser fingerprint mutation or stealth tuning.
- Local profile directory is gitignored.

# G01.SG04.PR01.ST01.T01 — C11.I01

## Purpose
Before any regional comparison, prove or fail closed that one anonymous Ozon session through one SG02 ProxyContext can reach the real Ozon product path and current `entrypoint-api` for one requested SKU.

## Input Contract
- one Ozon SKU;
- one anonymous Ozon cookie/storage-state JSON file;
- one city label and one explicit-scheme ProxyContext;
- no second city/proxy;
- no login/password/PVZ/manual browser work.

## Actions
1. Load the supplied anonymous guest cookie state.
2. Prove neutral curl_cffi egress identity through the single ProxyContext.
3. Request the real Ozon product URL `https://www.ozon.ru/product/<sku>/` through curl_cffi with the same cookies and ProxyContext; record HTTP status, response shape/title markers, and whether Ozon returned an antibot/network-denial page.
4. Independently request `https://www.ozon.ru/api/entrypoint-api.bx/page/json/v2?url=/product/<sku>/` through curl_cffi with the same cookies/ProxyContext and bounded dweb headers.
5. Require HTTP 200 + decodable JSON for data-access acceptance. If `pageInfo.url` is present, it must bind to the requested SKU.
6. Do not parse or compare regional price semantics in C11. Do not ask for a second proxy.
7. Persist only SAFE evidence; never persist cookie values or proxy credentials.

## Acceptance / Typed Evidence
- `OZON_SINGLE_PROXY_ENTRYPOINT_DATA_ACCESS_PROVEN`: neutral proxy egress proven and entrypoint returns HTTP 200 decodable JSON bound to the requested SKU when `pageInfo.url` is present.
- `OZON_SINGLE_PROXY_PRODUCT_PAGE_LOADED_ONLY`: product page returned HTTP 200 usable HTML but entrypoint data access is not yet proven.
- `OZON_SINGLE_PROXY_GUEST_SESSION_BLOCKED`: marketplace returns 401/403/antibot/network-denial for the single guest session.
- `OZON_SINGLE_PROXY_O3_HEADERS_STALE`: entrypoint returns HTTP 400.
- `OZON_SINGLE_PROXY_PRODUCT_BINDING_UNPROVEN`: entrypoint JSON cannot be bound to the requested SKU.
- `OZON_SINGLE_PROXY_TRANSPORT_FAILED`: neutral/proxy transport cannot be proven.

## Failure Conditions
- second proxy/city is requested;
- Playwright/Selenium/browser interaction is introduced;
- login/PVZ selection is introduced;
- HTTP reachability alone is mislabeled as entrypoint data success;
- price-region comparison is attempted before this gate passes.

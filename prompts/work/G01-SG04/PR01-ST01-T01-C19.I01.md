# G01.SG04.PR01.ST01.T01 — C19.I01

## Goal
Prove whether the exact sticky mobile session selected by the successful C18 Claude mobile-proxy selector can access the Ozon internal entrypoint endpoint directly with zero cookies and zero browser runtime.

## Input Contract
- Existing local C18 SAFE report at `parser/core/local/probes/ozon_mobile_proxy_selector_report.json` with gate `OZON_STICKY_MOBILE_OPERATOR_SELECTED`.
- Visible combined proxy input `host:port:user:pass` or `scheme://host:port:user:pass`.
- One Ozon SKU.

## Required Flow
1. Read the exact `session_id` and selected public egress IP from the C18 SAFE report.
2. Rebuild the proxy username with exactly that same `hold-session-session-<id>` value; do not rotate to a new session.
3. Through that exact ProxyContext, call the neutral identity endpoint and require the public IP to match C18 selected IP.
4. With the same ProxyContext and no cookies, call `https://www.ozon.ru/api/entrypoint-api.bx/page/json/v2?url=/product/<sku>/` directly.
5. Do not request Ozon home or product HTML. Do not use Playwright, Selenium, Chrome, login or PVZ.
6. Use the recovered dweb `x-o3-*` headers and curl_cffi impersonation sequence.
7. Challenge JSON must never count as product data. Price binding must use the recovered exact parser (`layout -> stateId -> widgetStates`) and fail closed on ambiguity.

## Diagnostics
- Proxy input is visible; no password masking/getpass.
- Credentials and cookie values must never be persisted.
- SAFE report may persist public IP/operator/session-id and request status/JSON metadata.

## Acceptance
`OZON_SAME_STICKY_DIRECT_ENDPOINT_ZERO_COOKIE_DATA_ACCESS_PROVEN`

## Typed non-acceptance
- `OZON_SAME_STICKY_C18_REPORT_INVALID`
- `OZON_SAME_STICKY_PROXY_AUTH_FAILED`
- `OZON_SAME_STICKY_IDENTITY_MISMATCH`
- `OZON_SAME_STICKY_DIRECT_ENDPOINT_CHALLENGED`
- `OZON_SAME_STICKY_O3_HEADERS_STALE`
- `OZON_SAME_STICKY_PRODUCT_BINDING_FAILED`
- `OZON_SAME_STICKY_JSON_WITHOUT_PRICE`
- `OZON_SAME_STICKY_TRANSPORT_FAILED`

## Evidence
SAFE report: `parser/core/local/probes/ozon_same_sticky_direct_c19_report.json`.

## Failure conditions
Any use of a newly rotated sticky session, cookies, Ozon home warmup, product HTML, browser runtime, hidden password input, or persistence of proxy credentials invalidates this cycle.

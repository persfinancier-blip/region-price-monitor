# Immutable Prompt — G01.SG04.PR01.ST01.T01.C25.I01

## Goal
Calibrate the repository-owned image solver coordinates from C23/C24 against the actual live Ozon CAPTCHA DOM geometry. Prove what solver `x/y` means relative to the rendered `#image` and `#puzzle` elements before any challenge answer submission or pointer automation is considered.

C25 is geometry evidence only. It must not move the puzzle, click, drag, submit, mutate challenge state, or claim CAPTCHA acceptance.

## Input Contract
- One visible runtime proxy string: `host:port:user:pass` (or explicit scheme form).
- Optional Ozon SKU; default may reuse the accepted reference SKU.
- Existing C23/C24 mobile selector, challenge acquisition, payload decoder, image fetcher and local solver.
- Existing repository-owned hidden Chrome proxy bridge.

## Runtime Contract
One continuous run:

`fresh sticky mobile -> same-IP recheck -> zero-cookie Ozon challenge -> exact background/puzzle -> local solver -> hidden Chrome on SAME ProxyContext -> browser egress check -> live captchaURL render -> #image/#puzzle geometry snapshot -> solver-to-DOM coordinate calibration -> same-IP postcheck`

No historical expected IP/session may be required.

## Implementation Contract
1. Ask for proxy credentials exactly once.
2. Select a fresh accepted Russian mobile sticky session and bind one `ProxyContext`.
3. Obtain a live Ozon challenge and solve its exact embedded background/puzzle images locally.
4. Record the alpha bounding box of the movable puzzle image because solver `x/y` is the top-left of the cropped alpha shape, not necessarily the full PNG canvas.
5. Start hidden/headless Chrome through `LocalBrowserProxyBridge` derived from the SAME `ProxyContext`.
6. Verify browser public egress equals the fresh selected IP.
7. Navigate the browser to the exact live `captchaURL` in memory and wait for `#image` and `#puzzle`.
8. Read only DOM geometry/computed-style metadata: bounding rectangles, tag, natural/client dimensions, CSS position/left/top/transform/display.
9. Compute:
   - background native-to-DOM scale;
   - puzzle native-to-DOM scale;
   - solver target shape position in viewport coordinates;
   - target full puzzle-element position after correcting for transparent alpha padding;
   - diagnostic `delta_x`/`delta_y` from current puzzle element position.
10. Save one local screenshot under Git-ignored evidence.
11. Recheck the same sticky IP after calibration. Continuity loss is a typed failure.
12. Never call `/abt/captcha/result`, never perform click/drag/pointer/mouse events, never use `ActionChains`, and never submit challenge state.
13. Never persist proxy credentials, full challenge URL, cp token or full signed image URLs in SAFE report.

## Acceptance Criteria
Deterministic:
- pure geometry function correctly translates solver alpha-crop coordinates into DOM target-element coordinates at scale 1 and non-1 scale;
- invalid/zero dimensions fail closed;
- source audit proves no historical C18/C19 dependency, challenge submission, clicks, drag, pointer/mouse automation or `ActionChains`;
- SAFE contract contains explicit no-submission/no-secret flags.

Live success gate:
- `OZON_CAPTCHA_DOM_GEOMETRY_CALIBRATED` — fresh sticky continuity confirmed, live challenge solved locally, browser egress matches selected IP, `#image` and `#puzzle` geometry is observed, finite positive scales and diagnostic deltas are computed, screenshot saved, and postcheck continuity remains true.

## Failure Conditions
- solver coordinate treated as a drag distance without DOM evidence;
- transparent alpha padding ignored;
- browser uses a different egress identity;
- missing/invalid DOM geometry represented as calibrated;
- any challenge answer submission or pointer automation;
- credentials/full signed URLs persisted.

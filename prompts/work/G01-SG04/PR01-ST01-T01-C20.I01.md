# Immutable Prompt — G01.SG04.PR01.ST01.T01.C20.I01

## Goal
Create a repository-owned, self-contained local slider/puzzle CAPTCHA analysis engine and a safe Ozon challenge fingerprint/capture probe. The implementation must not depend at runtime on third-party CAPTCHA solving services, remote solver APIs, browser automation, or availability of external source repositories.

## Input Contract
- Existing C19 local/Git-ignored raw challenge evidence under `parser/core/local/probes/ozon_same_sticky_direct_c19/`.
- Existing C18 SAFE report for exact selected sticky-session continuity when a live challenge fetch is requested.
- Visible operator-supplied proxy string only at runtime when live fetch is needed; credentials must never be committed or persisted.
- Local image bytes for deterministic slider/puzzle solver tests.

## Implementation Contract
1. Implement a clean-room local image solver under `parser/core/captcha/` using repository-owned source code only.
2. Do not copy third-party solver source code or strip license/attribution from copied code. Runtime source must contain no dependency on third-party solver servers or repositories.
3. Support two generic local strategies:
   - contour/edge matching for a movable piece against a background gap;
   - image-difference localization when both complete and gapped backgrounds are available.
4. Return structured result with target coordinates, score/confidence, strategy and typed failure rather than silently guessing.
5. Add deterministic synthetic tests proving both algorithms and low-confidence/fail-closed behavior.
6. Add an Ozon C20 challenge probe that:
   - reads C19 raw challenge JSON locally;
   - extracts challenge metadata without persisting secret URL query values;
   - fingerprints likely challenge type/provider from response content;
   - optionally fetches the challenge URL through the exact C18 sticky ProxyContext when operator supplies the visible combined proxy string;
   - stores raw fetched bodies/assets only under Git-ignored local probe paths;
   - emits a SAFE report containing hosts/content classification/counts only, not credentials, cookies, challenge tokens or full signed URLs.
7. No browser, Playwright, Selenium, undetected-chromedriver, Docker, external CAPTCHA solver API, or manual CAPTCHA solving is permitted in this cycle.
8. Do not automate target-specific CAPTCHA submission in C20. Submission semantics must be derived from fresh challenge evidence in a later immutable cycle; do not invent them.

## Output Contract
- `parser/core/captcha/__init__.py`
- `parser/core/captcha/models.py`
- `parser/core/captcha/slider.py`
- `tools/probe_ozon_challenge_c20.py`
- deterministic tests under `tests/`
- Windows runner `tests/RUN_OZON_CHALLENGE_C20.bat`
- required local dependencies explicitly declared in `parser/core/requirements.txt`

## Acceptance Criteria
Deterministic acceptance requires:
- synthetic contour/edge test locates the expected horizontal target within tolerance;
- synthetic image-difference test locates the expected target within tolerance;
- ambiguous/no-signal inputs fail closed or report low confidence;
- source audit proves no external solver API/server/browser dependency in `parser/core/captcha/`;
- challenge probe never persists proxy credentials or full challenge token URLs.

Live C20 acceptance is one of:
- `OZON_CHALLENGE_CAPTURED_AND_FINGERPRINTED` when fresh challenge content is safely captured through exact sticky context; or
- a typed BLOCKED gate identifying absent/invalid C19 evidence, sticky mismatch, proxy auth/transport failure, or challenge fetch failure.

C20 does NOT claim the Ozon CAPTCHA has been solved. A target-specific solve/submit cycle may be proposed only after fresh C20 evidence reveals the actual challenge assets and protocol.

## Evidence
- deterministic test output;
- SAFE report `parser/core/local/probes/ozon_challenge_c20_report.json`;
- raw challenge material only under Git-ignored `parser/core/local/probes/ozon_challenge_c20/`.

## Failure Conditions
- copied third-party source with removed attribution/license;
- runtime call to external CAPTCHA-solving service;
- browser dependency;
- credentials/tokens/cookies/full signed challenge URLs persisted;
- guessed target-specific submission protocol;
- synthetic tests pass only by hard-coded target coordinates.

# G01.SG04.PR01-ST01-T01.C06.I01

## Goal
Before any Ozon endpoint/session/price work, prove that the real Ozon product page is visibly usable in a normal Chrome window through the accepted SG02 ProxyContext.

## Scope
- control product page only: `https://www.ozon.ru/product/<sku>/`;
- visible/non-headless browser;
- same SG02 ProxyContext only;
- neutral browser egress proof before marketplace navigation;
- no composer API, no cookie bootstrap, no price parsing in this cycle.

## Acceptance
Browser visibly opens the requested Ozon product page through the proxy. Operator can inspect it. SAFE REPORT records only bounded navigation metadata and browser egress identity, no page data/cookie values/secrets.

## Failure
Browser startup/proxy-binding/navigation/challenge result is explicit. Do not continue into Ozon data endpoints until the owner supplies/approves the required endpoint work.

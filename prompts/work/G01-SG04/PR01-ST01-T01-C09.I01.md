# G01.SG04.PR01.ST01.T01 — C09.I01

## Purpose
Discriminate why the zero-human Ozon bootstrap failed before changing login/session architecture.

## Input Contract
- one CityRecord / SG02 ProxyContext with explicit proxy scheme;
- one Ozon SKU;
- accepted C08 evidence showing Ozon incident page `Похоже, нет соединения` in headless Playwright;
- no Ozon credentials and no manual cookies.

## Actions
1. Prove a curl_cffi neutral egress identity through the supplied ProxyContext.
2. Run Playwright Chromium headless through a browser proxy projection derived only from the same ProxyContext; prove its neutral egress identity, then navigate to the Ozon SKU and observe whether the current entrypoint request appears or an Ozon denial/challenge page appears.
3. Run Playwright Chromium headed through the same ProxyContext with zero user interaction; prove its neutral egress identity, then perform the same Ozon navigation/observation.
4. Do not login, solve captcha, select city/PVZ, press Enter inside browser flow, or import manual cookie/profile state.
5. Record only SAFE evidence: egress identity, HTTP/document status when available, title, typed denial markers, incident-id presence, entrypoint observed boolean, bridge safe state. Screenshots may be local/Git-ignored.

## Acceptance / typed evidence
This is a diagnostic cycle, not SG04 acceptance.

- `OZON_HEADLESS_SPECIFIC_DENIAL_EVIDENCED`: same proven proxy egress, headless receives Ozon denial while headed does not and/or headed observes entrypoint.
- `OZON_ROUTE_DENIED_BOTH_BROWSER_MODES`: same proven proxy egress, both modes receive the Ozon network/VPN denial page.
- `OZON_BROWSER_PROXY_BINDING_UNPROVEN`: neutral identity missing/mismatched.
- `OZON_ENTRYPOINT_OBSERVED_HEADLESS` / `OZON_ENTRYPOINT_OBSERVED_HEADED`: explicit positive observation.
- otherwise `OZON_ACCESS_DISCRIMINATOR_INCONCLUSIVE`.

## Evidence
SAFE JSON report plus local screenshots. No credentials, cookies, authorization values, raw storage state or proxy secrets in Git/report.

## Failure Conditions
- any manual user interaction is required;
- browser runs direct instead of selected ProxyContext;
- headed success is silently treated as Linux production acceptance without later zero-human Linux/Xvfb proof;
- denial is mislabeled as generic network failure when an Ozon incident page was actually received.

# G01 / SG04 / PR01 / ST01 / T01 / C29.I01

## Goal
Test the exact already-bound mobile sticky proxy identity supplied by the operator, without silently rotating to a fresh session.

## Contract
1. Load the gitignored local test proxy from `parser/core/local/ozon_test_proxy.txt` unless `--proxy` is explicitly supplied.
2. Require the proxy username to already contain `hold-session-session-<id>`.
3. Preserve that username and session id exactly; C29 must not call the rotation selector.
4. Prove the preserved session's current public IP.
5. Start Camoufox with the exact same preserved proxy credentials and require browser IP == preserved session IP.
6. Keep the browser cookie jar inside the same browser context.
7. Request Ozon entrypoint/composer through browser-native `fetch()` in that same context.
8. Parse only the exact requested SKU using the existing strict Ozon price parser.

## Acceptance
PASS only when the exact preserved sticky session is used end-to-end and the requested SKU price is returned.

Gate: `OZON_PRESERVED_STICKY_PRICE_PROVEN`.

## Failure semantics
- Missing/non-bound cached proxy: explicit C29 proxy error.
- Preserved sticky IP unavailable: `OZON_C29_STICKY_IP_UNPROVEN`.
- Browser egress differs: `OZON_C29_BROWSER_STICKY_IP_MISMATCH`.
- Browser/API remains challenged or no exact price: `OZON_PRESERVED_STICKY_NO_PRICE`.

## Security
Proxy credentials and cookie values remain local/in memory and are not committed or printed. No CAPTCHA interaction or submission is performed.

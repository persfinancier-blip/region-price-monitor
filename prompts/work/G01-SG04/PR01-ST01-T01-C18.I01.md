# G01.SG04.PR01.ST01.T01 — C18.I01

## Input Contract
- One mobile proxy in Claude's combined form: `host:port:user:pass` (or explicit-scheme equivalent).
- Password must be visibly typed in diagnostic mode; it must not be masked.
- Up to 15 sticky-session attempts.
- No Ozon cookies, browser, Playwright, Selenium, login or PVZ are required for this selector proof.

## Goal
Reproduce exactly the recovered Claude `mobile_proxy.py` selector mechanism remembered by the owner:
`rotate hold-session-session-<id> in proxy login -> curl_cffi neutral IP/operator check -> stop when MTS/Beeline/MegaFon/Tele2-T2/Yota is selected`.

## Actions
1. Accept the whole proxy credential string visibly from the console.
2. Support rotation from three recovered login forms: bare login, `hold-query`, and already-bound `hold-session-session-<id>`; backward-compatible hold-session forms may also be accepted.
3. For each attempt generate a fresh session id and replace/append exactly one `hold-session-session-<id>` suffix.
4. Through the resulting ProxyContext call the neutral identity endpoint using `curl_cffi`, never Playwright.
5. Print every attempt live: session id, status, IP, mobile flag and detected operator. Do not wait until the final report to expose diagnostic evidence.
6. Stop immediately on a successful mobile operator match.
7. Distinguish proxy authentication failure (`407`/equivalent) from transport failure, unknown operator and operator-not-found.
8. Persist only SAFE evidence. Never persist proxy username/password.

## Acceptance
`OZON_STICKY_MOBILE_OPERATOR_SELECTED` only when one attempt proves `mobile=true` and the operator matches MTS, Beeline, MegaFon, Tele2/T2 or Yota/Scartel.

## Typed non-acceptance
- `OZON_STICKY_PROXY_AUTH_FAILED`
- `OZON_STICKY_PROXY_TRANSPORT_FAILED`
- `OZON_MOBILE_FLAG_SEEN_OPERATOR_UNPROVEN`
- `OZON_STICKY_MOBILE_OPERATOR_NOT_FOUND`

## Evidence
- Runner: `tests/RUN_OZON_CLAUDE_MOBILE_PROXY_C18.bat`
- SAFE report: `parser/core/local/probes/ozon_mobile_proxy_selector_report.json`
- No browser runtime is permitted.
- Password is visible during input but is never written to report/files.

## Failure Conditions
- Hidden/masked password input.
- Browser/Playwright/Selenium used for a probe.
- Credentials persisted.
- `hold-query` or already-bound-session rotation unsupported.
- Generic transport gate used for an identifiable proxy-auth failure.

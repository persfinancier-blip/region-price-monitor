# G01.SG04.PR03.ST01.T01.C02.I01

## Role
Validate and preserve requested-product Ozon price parsing against responses produced under an accepted verified C02 OzonContext. Stay engine-neutral.

## Goal
Parse the requested product's `webPrice` semantic state regardless of whether the accepted autonomous context engine used `curl_cffi`, hidden/headless Selenium/Chrome, or both.

## Inputs
- sanitized successful product-page/state fixtures produced under verified requested-city C02 OzonContext;
- existing `parse_price()` behavior.

## Actions
1. Preserve the requested product `webPrice` state as semantic price authority.
2. Ensure parser inputs are normalized to content/state, not tied to transport/browser implementation objects.
3. Extract evidenced price/card/regular/original/base fields, currency and availability where supported.
4. Keep unrelated recommendation/installment/page-wide ₽ values out of the result.
5. Return explicit malformed/missing-widget semantic failure.

## Output Contract
Deterministic engine-neutral parser output for the requested SKU, or explicit semantic failure.

## Acceptance
- same semantic output for equivalent accepted content from HTTP or hidden-browser engine;
- no networking/session/browser control in parser;
- no arbitrary ₽ scraping;
- missing/malformed `webPrice` is not transport failure.

## Failure Boundary
No context engine, collector, persistence, scheduler, SG05 fallback or proxy changes.

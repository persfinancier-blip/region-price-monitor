# G01 / SG04 / PR01 / ST01 / T01 / C33.I01

## Goal
Verify that the Camoufox browser reaches HTTPS targets through the configured proxy over a genuinely secure browser context before any further Ozon anti-bot work.

## Contract
1. Read the existing local cached proxy credential without persisting it to Git.
2. If the cached proxy value has no explicit scheme, test both `http://host:port` and `https://host:port` as proxy protocol candidates. Do not infer proxy protocol from port number alone.
3. For each candidate, navigate Camoufox to a neutral HTTPS target and to the Ozon HTTPS home URL only.
4. Record final URL, `location.protocol`, `window.isSecureContext`, HTTP status, and Playwright response security details when available.
5. Never set `ignore_https_errors=True`.
6. Do not call Ozon entrypoint/composer APIs and do not interact with any CAPTCHA.

## Acceptance
A proxy scheme is secure only when both neutral HTTPS and Ozon navigation finish on `https://`, report `location.protocol == "https:"`, and `window.isSecureContext == true`.

Gates:
- `OZON_C33_SECURE_PROXY_SCHEME_PROVEN scheme=<http|https>` when exactly one scheme is secure.
- `OZON_C33_BOTH_PROXY_SCHEMES_SECURE` when both are secure.
- `OZON_C33_NO_SECURE_BROWSER_PROXY_PATH` when neither is secure.

## Failure semantics
No further Ozon browser/session work should rely on a proxy path that fails this TLS security preflight.

# Immutable Prompt — G01.SG04+SG05 Ozon reader assembly C26.I01

## Goal
Assemble the already-proven SG04 proxy-first Ozon transport/entrypoint parser and the preserved SG05 personalized authenticated legacy reader behind one explicit price-reader contract:

`SKU + current City ProxyContext -> PRICE | CHALLENGE | typed failure`

and, only with explicit operator/caller intent:

`non-price SG04 result -> SG05 authenticated legacy cookies -> PRICE | typed legacy failure`.

## Hard boundaries
1. SG04 primary uses zero legacy cookies/profile and never enters SG05 automatically.
2. SG05 keeps personalized authenticated user cookies/tokens as required secret runtime material.
3. SG05 proxy remains optional; do not make the new city proxy a prerequisite for the historical working fallback.
4. No CAPTCHA answer submission, pointer automation or challenge-state mutation.
5. Challenge is a first-class non-price result. Never serialize it as price=0.
6. Exact SKU binding is mandatory for entrypoint JSON parsing.
7. Existing `fetch_price(...)` callers remain backward compatible.

## Implementation
- `parser/core/ozon.py`
  - add reusable SG04 `fetch_price_proxy_first`;
  - restore/preserve explicit SG05 `fetch_price_legacy_authenticated`;
  - keep backward-compatible `fetch_price`;
  - add `read_price` glue with `allow_legacy_fallback=False` by default.
- Add deterministic C26 tests for exact price, typed challenge, no implicit fallback and legacy explicit fallback.
- Add an operator runner that proves the assembled contract on one SKU/current mobile sticky session and can explicitly invoke a discovered/profile-selected SG05 fallback.

## Acceptance
Deterministic:
- SG04 exact entrypoint fixture -> status=price and positive exact price;
- challenge fixture -> status=challenge with no price field;
- `read_price(... allow_legacy_fallback=False)` never calls legacy;
- explicit fallback may call legacy;
- legacy `proxy` is optional;
- source contains no challenge submission/pointer automation.

Live:
- runner prints either a real Ozon price or an explicit typed SG04 block;
- if operator explicitly chooses a valid authenticated profile, fallback prints the real price or typed legacy failure.

## Failure
- automatic fallback;
- fake zero price;
- loss of legacy authenticated-cookie semantics;
- mandatory proxy added to SG05;
- secret cookies/tokens written into Git/evidence;
- CAPTCHA bypass code.

# G01.SG04.PR01.ST01.T01.C07.I01

## Goal
Prove that the future server runtime can reach the real Ozon website through SG02 ProxyContext without Chrome, Selenium, Playwright or user interaction.

## Input Contract
- explicit-scheme ProxyContext with city-bound proxy credentials;
- control Ozon SKU;
- official Ozon product page only: `https://www.ozon.ru/product/<sku>/`.

## Actions
1. Confirm the curl_cffi stack egress through `https://api.i.pn/json/`.
2. Request the official Ozon product page through the SG02 curl_cffi adapter with browser-like TLS impersonation.
3. Record bounded HTTP response evidence only: status, content type/server headers, title when present, body length/hash, antibot/captcha marker, local Git-ignored body path.
4. Do not call Ozon data endpoints, bootstrap cookies or parse prices.

## Acceptance
- `OZON_SITE_REACHABLE` for an HTTP response from the requested HTTPS Ozon host;
- `OZON_SITE_REACHABLE_ANTIBOT_RESPONSE` when Ozon returns an HTTP antibot/captcha response. This proves site reachability only, not data access.

## Failure
No HTTP response / proxy or connection failure -> `OZON_SITE_UNREACHABLE`.

## Boundary
No browser dependency, no user interaction, no endpoint guessing, no price semantics, no antibot bypass work.

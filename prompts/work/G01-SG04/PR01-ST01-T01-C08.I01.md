# G01.SG04.PR01.ST01.T01 — C08.I01

## Immutable Prompt

### Goal
Prove or fail closed on a **zero-human Ozon session bootstrap** suitable for the future Linux server runtime.

The experiment must separate the rare browser bootstrap from the steady-state reader:

`ProxyContext -> headless Playwright -> Ozon session/cookies/current entrypoint request -> close browser -> curl_cffi -> same entrypoint request`

### Input Contract
- one Ozon SKU;
- one CityRecord / SG02 ProxyContext with explicit proxy scheme;
- no Ozon login/password in this first cycle;
- no manually prepared cookies/profile;
- no manual city/PVZ selection;
- no manual captcha solving;
- no Enter/input while the browser is running.

### Actions
1. Derive browser routing only from SG02 ProxyContext. For HTTPS upstream proxy support, reuse the already-proven local browser proxy bridge; do not invent a second proxy authority.
2. Launch Playwright Chromium **headless** with zero user interaction.
3. Navigate to Ozon home and the requested product URL.
4. Observe network traffic and capture only the current Ozon `entrypoint-api.bx/page/json/v2` request for the requested product plus a bounded allow-list of non-secret request headers needed for replay. Never persist raw Cookie/Authorization headers.
5. Export browser cookies/storage state only to Git-ignored local runtime evidence.
6. Close Playwright completely.
7. Replay the captured current entrypoint request using `curl_cffi` through the same ProxyContext and the cookies obtained automatically in step 5.
8. Treat HTTP 200 + decodable JSON for the requested product entrypoint as data-access/bootstrap evidence. Do **not** parse or claim the final price field in this cycle.
9. Record a SAFE REPORT with bounded transport/status/antibot/capture metadata and no credentials/cookie values.

### Output Contract
One typed result:
- `OZON_ZERO_HUMAN_BOOTSTRAP_AND_ENTRYPOINT_PROVEN`
- `OZON_ZERO_HUMAN_BROWSER_CHALLENGED`
- `OZON_ZERO_HUMAN_ENTRYPOINT_NOT_OBSERVED`
- `OZON_ZERO_HUMAN_ENTRYPOINT_REPLAY_BLOCKED`
- `OZON_ZERO_HUMAN_ENTRYPOINT_NON_JSON`
- explicit dependency/proxy/transport failure.

### Acceptance Criteria
PASS only when all are true:
- browser was headless;
- no user interaction occurred;
- browser routing came from the same ProxyContext;
- a current entrypoint request for the requested SKU was observed automatically;
- browser was closed before steady-state replay;
- curl_cffi replay used the same ProxyContext and automatically obtained cookies;
- replay returned HTTP 200 JSON;
- no price value is accepted merely from the first `webPrice`/`webSale` occurrence;
- no secret cookie/token/proxy credential is committed or emitted in SAFE REPORT.

### Evidence
- deterministic contract tests;
- local Git-ignored storage state/raw diagnostic body;
- SAFE REPORT;
- operator live run on current environment;
- later Linux/H01 rerun is required before declaring Linux production acceptance.

### Failure Conditions
Any manual login/captcha/PVZ/Enter requirement; browser required during steady-state replay; direct-network fallback; second proxy authority; captured secrets in Git/report; pinned stale frontend headers used as semantic authority; HTTP reachability mislabeled as data access; price inferred from an unrelated widget.

# G01.SG04.PR03.ST01.T01.C01.I01

## Role
Validate/preserve only the requested-product Ozon `webPrice` semantic parser against accepted fresh-session fixtures.

## Goal
Parse regional price fields from the requested product's current `webPrice` state without mixing in transport/session/context logic.

## Inputs
Sanitized successful product-page fixtures obtained under verified OzonContext plus current `parse_price` behavior.

## Actions
1. Locate the requested product `webPrice` state from accepted fixtures.
2. Preserve/extract evidenced price fields: primary price and card/regular/original/base values where present.
3. Preserve currency and availability only where supported by the widget state.
4. Return explicit malformed/missing-widget semantic signal.
5. Add fixture tests proving unrelated recommendation/installment ₽ text is not accepted as the requested product price.

## Output Contract
Pure parser result for requested product price fields or explicit semantic parse failure.

## Acceptance
- requested-product widget/state is the semantic source;
- no arbitrary page-wide ₽ regex fallback;
- malformed/missing widget distinct from transport/context failure;
- no networking/session/bootstrap inside parser.

## Failure Boundary
No collector, DB/CSV, scheduler, browser fallback or transport redesign.

# Immutable Prompt — G01.SG04.PR01.ST01.T01.C21.I01

## Goal
Perform repository-owned, local-only static/protocol analysis of the live Ozon CAPTCHA evidence captured in C19/C20, correcting the C20 assumption that puzzle images must be fetched as standalone assets.

## Input Contract
- C19 local/Git-ignored raw challenge JSON containing the original `captchaURL`.
- C20 local/Git-ignored CAPTCHA HTML/JS assets.
- No new Ozon request is required.

## Implementation Contract
1. Parse the C19 `captchaURL` locally and inspect query parameter names/shape without printing or persisting full parameter values.
2. Attempt local base64/url-safe-base64/JSON structural decoding of query values; emit only SAFE metadata: parameter names, lengths, hashes, decoded types/keys and image-like byte metadata.
3. Statically inspect C20 `captcha_v11.js` evidence for protocol-relevant literals and the embedded VM bytecode behavior.
4. Record proven protocol facts including:
   - `/abt/captcha/result` candidate POST;
   - gzip JSON request body, JSON content type and credential inclusion;
   - `/abt/captcha/ok` and `/abt/captcha/fail` mobile terminal routes;
   - `abt_att`, `origin_referer`, `captchaDone`, `mode` web-flow parameters;
   - VM use of URL/query parsing, `atob`, `JSON.parse`, `#image`, `#puzzle`, pointer events and timing signals when present in captured bytecode.
5. Do not print or persist proxy credentials, cookies, challenge tokens, full signed URLs or decoded sensitive payload values.
6. Do not submit a CAPTCHA answer, emulate pointer trajectories, call `/abt/captcha/result`, or automate anti-bot bypass in this cycle.
7. No browser, Playwright, Selenium, Docker or external CAPTCHA solver service.

## Output Contract
- `tools/analyze_ozon_captcha_protocol_c21.py`
- `tests/test_wave2_ozon_captcha_protocol_c21.py`
- `tests/RUN_OZON_CAPTCHA_PROTOCOL_C21.bat`
- SAFE report `parser/core/local/probes/ozon_captcha_protocol_c21_report.json`

## Acceptance Criteria
- deterministic test proves query values are never emitted while decoded structural metadata is produced;
- live/local run identifies the actual C19 query parameter set;
- JS/bytecode evidence is summarized without copying secret payload values;
- no network request is made by C21;
- no CAPTCHA submission/solve path is implemented.

## Evidence Gates
- `OZON_CAPTCHA_QUERY_PAYLOAD_STRUCTURED` — a challenge query payload is locally decoded to structured metadata;
- `OZON_CAPTCHA_QUERY_STRUCTURE_CAPTURED` — query structure is captured but payload is opaque;
- typed BLOCKED gate for missing C19/C20 evidence.

## Failure Conditions
- output contains full `captchaURL` or query values;
- network request occurs;
- solver/submit logic is introduced;
- secrets are committed or persisted.

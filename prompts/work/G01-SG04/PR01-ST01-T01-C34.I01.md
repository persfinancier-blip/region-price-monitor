# G01 / SG04 / PR01 / ST01 / T01 / C34.I01

## Goal
Explain the visible Camoufox `Not Secure` label without conflating browser chrome with transport security.

## Inputs already proven
C33 live evidence proves the usable proxy scheme is HTTPS and that Ozon main navigation used TLS 1.3 with a `*.ozon.ru` certificate issued by GlobalSign and `window.isSecureContext=True`.

## Contract
1. Use only the C33-proven `https://` proxy scheme.
2. Navigate to Ozon only; do not request price APIs.
3. Do not interact with or submit CAPTCHA.
4. Capture main-document HTTPS/TLS evidence.
5. Observe all browser requests whose URL begins with `http://`.
6. Observe DOM `src`/`href` attributes beginning with `http://`.
7. Observe Resource Timing entries beginning with `http://`.
8. Observe browser console messages mentioning mixed/insecure/blocked content.
9. Redact query strings when printing insecure resource URLs.

## Acceptance
PASS when:
- main document remains HTTPS;
- `window.isSecureContext=True`;
- TLS details are available and certificate subject is for Ozon;
- no `http://` mixed resource is observed.

Gate: `OZON_C34_MAIN_TLS_VALID_NO_HTTP_MIXED_CONTENT`.

If insecure HTTP resources are found, return `OZON_C34_MIXED_HTTP_CONTENT_OBSERVED` and do not claim the visible browser label is merely cosmetic.

## Safety
No CAPTCHA submission, no pointer automation, no challenge-result endpoint, no price API request, and no proxy credentials persisted to GitHub.

# G01.SG04.PR01.ST01.T01 — C13.I01

## Purpose
After C12 proved that an empty curl_cffi session is challenged at Ozon home, determine whether a real Chromium browser through the same single SG02 ProxyContext can load Ozon autonomously without any user interaction.

## Input Contract
- one Ozon SKU;
- one city label;
- one explicit-scheme SG02 ProxyContext;
- Playwright/Chromium installed locally;
- no Ozon credentials, cookie files, PVZ/region selection or manual browser interaction.

## Actions
1. Prove neutral egress identity with curl_cffi through the ProxyContext.
2. Run Playwright Chromium headless through the same ProxyContext and open the Ozon product page.
3. Run Playwright Chromium headed through the same ProxyContext and open the same Ozon product page; the user must not click/type/solve anything.
4. For both modes, prove browser neutral egress identity matches curl_cffi.
5. Record document status, title, whether the Ozon entrypoint request is observed, and whether the page is a network-denial or antibot/captcha page.
6. Treat `Antibot Captcha` / captcha markers as blocked evidence, not inconclusive.
7. Save screenshots only under Git-ignored local probes. Never persist proxy credentials.

## Acceptance / Typed Evidence
- `OZON_ENTRYPOINT_OBSERVED_HEADLESS`: headless Chromium reaches the product application and observes the requested SKU entrypoint call.
- `OZON_ENTRYPOINT_OBSERVED_HEADED`: headed Chromium reaches the product application and observes the requested SKU entrypoint call while headless does not.
- `OZON_HEADLESS_SPECIFIC_BLOCK_EVIDENCED`: headless is denied/challenged while headed is not blocked or reaches entrypoint.
- `OZON_BLOCKED_BOTH_BROWSER_MODES`: both browser modes receive Ozon network-denial or antibot/captcha content.
- `OZON_BROWSER_PROXY_BINDING_UNPROVEN`: browser egress cannot be proven equal to the curl reference.
- `OZON_ACCESS_DISCRIMINATOR_INCONCLUSIVE`: none of the above can be established.

## Failure Conditions
- captcha is solved or bypassed;
- user clicks/types in the browser;
- login/password or manual cookies are introduced;
- a direct/no-proxy fallback occurs;
- captcha is mislabeled as a normal or inconclusive page.

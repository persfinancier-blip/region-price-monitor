# G01.SG04.PR01.ST01.T01.C02.I01

## Role
Execute only the repaired evidence-capture Task for current Ozon regional behavior. Do not implement the final parser/collector.

## Goal
Starting from no manually warmed Ozon profile/cookie file, determine which autonomous engine(s) can establish usable Ozon state for the requested city through the accepted SG02 ProxyContext: lightweight `curl_cffi`, hidden/headless Selenium/Chrome, or a deterministic combination of the two.

## Inputs
- current repository code (`ozon.py`, `warm_browser.py`, collector paths);
- accepted SG01 CityRecord and SG02 ProxyContext contracts;
- representative Ozon SKU(s) and city proxy configuration available to the executor.

## Actions
1. Start with no legacy `cookies.json` and no manually prepared browser profile.
2. Probe the lightweight `curl_cffi` path through the selected city ProxyContext.
3. If evidence shows the lightweight path cannot establish sufficient session/location state, probe an **automatic hidden/headless Selenium/Chrome path** using the same ProxyContext as network authority.
4. Hidden browser work must require zero human actions: no login, no manual city/PVZ selection, no Enter prompts, no manual captcha solve.
5. Record whether browser-created automatic cookies/session state can be reused directly or transferred to the lightweight HTTP path where evidenced.
6. Capture only sanitized response/session/location facts needed to answer:
   - which engine or engine sequence is sufficient;
   - which automatically created state is required;
   - what regional/location/delivery-context signals are observable;
   - whether requested city can be verified;
   - what anti-bot/session/browser failure forms occur.
7. Prove that every autonomous network path uses the requested city's ProxyContext. If browser proxy authentication/binding cannot be proven, return an explicit unproven verdict; never fall back to direct networking.
8. Record exact evidence paths/hashes/outcomes without credentials, tokens or authenticated proxy URI.

## Output Contract
Either:
- sanitized evidence bundle sufficient for PR01.ST02 to define an autonomous engine + city-verification contract; or
- `OZON_CONTEXT_CONTRACT_UNPROVEN` / `OZON_BROWSER_PROXY_BINDING_UNPROVEN` with exact missing evidence.

## Acceptance
- no legacy cookie/profile prerequisite;
- hidden Selenium/Chrome is allowed only as an automatic non-interactive engine;
- all autonomous network activity is bound to ProxyContext;
- no human browser action;
- no assumption that proxy IP alone proves Ozon effective city;
- secrets excluded from committed evidence.

## Failure Boundary
Do not implement final engine, parser, collector, manual fallback, persistence or scheduler. Do not add new mandatory CityRecord fields.

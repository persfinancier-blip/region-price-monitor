# G01.SG04.PR03.ST02.T01.C01.I01

## Role
Define per-SKU Ozon outcome classification from accepted SG02 transport, verified OzonContext and parser output.

## Goal
Stop collapsing unrelated Ozon failures into broad `403`/empty results and preserve city/SKU identity for every requested unit.

## Inputs
- SG02 TransportOutcome;
- verified/mismatch/unproven OzonContext state;
- PR03.ST01 parser result.

## Actions
1. Map proxy/auth/connect/timeout/HTTP failures from SG02 without relabeling them as semantic no-price.
2. Map context mismatch/unproven separately from transport success.
3. Map anti-bot/session rejection separately when evidenced.
4. Map HTTP 200 + missing/malformed `webPrice` as semantic failure, not proxy failure.
5. Preserve requested SKU/city and safe diagnostics.

## Output Contract
Typed Ozon outcome: success price or explicit transport/context/session/semantic failure.

## Acceptance
- broad exception does not become unconditional `403`;
- failure never becomes a valid-looking zero/empty price;
- city/SKU always retained;
- diagnostics contain no proxy/session credentials.

## Failure Boundary
No session bootstrap changes, collector persistence, scheduler or legacy fallback redesign.

# G01 / SG04 / PR01 / ST01 / T01 / C31.I01

## Goal
Reproduce the exact Camoufox bootstrap sequence from the standalone probe that previously yielded 9 cookies and HTTP 200 price access, while keeping one sticky proxy identity inside each attempt.

## Contract
1. Load the locally cached proxy credentials; never persist them to Git.
2. Create a fresh `hold-session-session-<id>` for each bounded attempt.
3. Prove the sticky public IP outside the browser before bootstrap.
4. Start Camoufox on that exact sticky identity.
5. The first browser navigation MUST be Ozon `HOME_URL`; do not visit a neutral/IP-check page in the browser before Ozon.
6. Reproduce the proven standalone bootstrap order exactly:
   - `expect_request("**/api/*-api.bx/page/json/v2**", timeout=30000)` around the first Ozon `goto`;
   - if that wait fails/times out, perform a second Ozon `goto`, then wait 5 seconds;
   - always wait another 2.5 seconds before reading cookies.
7. Read the complete browser cookie jar and report names/count only, including whether `__Secure-ext_xcid` appeared.
8. Attempt entrypoint then composer using browser-native `fetch()` in the same browser context.
9. Only after the Ozon API result, verify browser egress IP through a second page and require it to equal the pre-proven sticky IP.
10. No CAPTCHA interaction or submission.

## Acceptance
PASS when the exact requested SKU price is returned and the post-result browser IP still equals the pre-proven sticky IP.

Gate: `OZON_EXACT_BOOTSTRAP_PRICE_PROVEN`.

## Failure semantics
- proxy/IP failure -> explicit error;
- browser egress mismatch -> `OZON_C31_BROWSER_STICKY_IP_MISMATCH`;
- no exact price after all bounded attempts -> `OZON_C31_NO_READY_SESSION_FOUND`.

## Evidence
Print per attempt: session id, pre-proven IP, whether the first Ozon API request was observed, whether second navigation was used, cookie count/names, `ext_xcid`, UI challenge state, API result, and post-result browser IP. Cookie values and proxy credentials remain memory-only.

# G01.SG05.PR01.ST01.T01.C02.I01

## Role
Inventory the current working legacy regional mechanism exactly as it exists. Do not redesign primary proxy-first behavior.

## Goal
Produce an evidence-backed map of all legacy regional entrypoints/artifacts and explicitly preserve the fact that the current working Ozon fallback depends on **personalized authenticated cookies/tokens from a user-confirmed Ozon login**.

## Inputs
- current `parser/core/cli.py`;
- current `parser/core/warm_browser.py`;
- current `parser/core/ozon.py`;
- existing runtime-local profile/cookies artifacts if available for inspection by type/path only;
- SG04 proxy-first contract for separation.

## Actions
1. Inventory `review_profiles`, `repair_regions`, `add_new_regions`, `warm_region`, `browser_fetch_prices`, `get_wb_dest`, `load_cookies`, profile directories and `cookies.json` call sites.
2. Classify the current Ozon `cookies.json` as personalized authenticated secret material produced after confirmed user login, not generic anonymous cookies.
3. Record where authenticated cookies are loaded/consumed and how expiry/blocking is currently detected.
4. Record only names/paths/types/flow; never copy raw cookie values, tokens or authenticated headers into Git/evidence.
5. Separate this legacy authenticated-cookie requirement from SG04's new proxy-first mechanism.

## Output Contract
Legacy capability/artifact map with explicit authenticated-cookie dependency and secret-handling boundary.

## Acceptance
- personalized authenticated cookie semantics are explicit;
- no raw secret values are committed/logged;
- SG04 is not given a personalized-cookie requirement;
- no implementation changes.

## Failure Boundary
Do not replace current cookies with anonymous/session-only cookies, do not implement fallback or primary code, and do not add auth material to CityRecord.

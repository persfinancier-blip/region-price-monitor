## Goal
Define the exact invocation boundary between proxy-first primary operation and interactive legacy fallback/support.

## Input
Accepted legacy inventory + SG01–SG04 primary contracts.

## Output contract
Define rules proving:
1. primary startup/collection must not call `review_profiles`, `repair_regions`, `add_new_regions`, `warm_region`, `browser_fetch_prices` or `get_wb_dest` implicitly;
2. primary CityRecord does not require `ozon_profile_dir`, profile path or cookies file;
3. primary Ozon failure remains a typed failure and does not automatically open a browser;
4. legacy/fallback operations require explicit operator intent;
5. automatic fallback switching is outside G01 unless separately justified.

## Acceptance
Boundary is deterministic and testable; legacy remains preservable; primary can exist with zero legacy artifacts.

## Failure conditions
If separation requires adding legacy fields to primary CityRecord or weakening SG03/SG04, return `STRUCTURAL_REPAIR_REQUIRED`.

## Scope
Contract/interface work only. Do not implement fallback code, marketplace parsers, persistence or scheduler.

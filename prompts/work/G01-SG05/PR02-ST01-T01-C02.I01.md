# G01.SG05.PR02.ST01.T01.C02.I01

## Role
Preserve the currently working Ozon legacy fallback capability without changing the new SG04 proxy-first path.

## Goal
Keep an intentionally invokable Ozon fallback that consumes the existing **personalized authenticated user profile/cookies** and preserves current curl_cffi/browser behavior sufficiently to remain usable.

## Inputs
Accepted SG05 PR01 C02 boundary + current legacy Ozon profile/cookies/browser implementation.

## Actions
1. Preserve loading/consumption of personalized authenticated cookies/tokens from the legacy runtime profile.
2. Preserve current authenticated curl_cffi/browser fallback semantics where still required.
3. If auth cookies are absent/expired/rejected, return explicit legacy auth/profile failure; never silently replace with anonymous cookies and claim success.
4. Keep real cookies/tokens local and secret; redact diagnostics and test evidence.
5. Require explicit legacy/fallback invocation; primary SG04 failure must not enter this path automatically.

## Output Contract
Explicit legacy Ozon fallback capability with authenticated-profile provenance and typed failure state.

## Acceptance
- current authenticated cookie requirement is preserved;
- valid existing profile remains consumable;
- expired/invalid auth is explicit;
- no secret leakage;
- no primary SG04 dependency or automatic browser fallback.

## Failure Boundary
Do not modernize away the authenticated-cookie behavior, do not persist secret material in Git/tests, and do not redesign primary Ozon logic.

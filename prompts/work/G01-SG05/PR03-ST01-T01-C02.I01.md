# G01.SG05.PR03.ST01.T01.C02.I01

## Role
Prove both SG05 C02 sides: primary independence and authenticated fallback reachability.

## Goal
Demonstrate that the new proxy-first primary never needs legacy personalized cookies/profile, while the current fallback still works only with its real authenticated user-cookie semantics preserved.

## Inputs
Accepted SG05 PR01/PR02 C02 outputs + SG04 primary interfaces.

## Actions
1. Add spies/tests proving primary does not call legacy profile/cookie/warm/browser support paths.
2. Prove explicit fallback reaches the preserved authenticated cookie loader/profile path.
3. Add negative regression showing anonymous/generic substitute cookies do not count as proof of current fallback compatibility.
4. Define a desktop/live smoke procedure using runtime-local authenticated profile material without recording secret values.
5. Verify invalid/expired authenticated cookies produce explicit legacy failure/maintenance state.

## Output Contract
Primary-isolation evidence + authenticated-fallback reachability/regression evidence + safe desktop smoke procedure.

## Acceptance
- primary is independent of legacy auth cookies;
- explicit fallback uses preserved personalized authenticated state;
- no raw secrets in tests/evidence;
- anonymous substitution cannot falsely pass;
- browser/live smoke deferred only when host capability requires it.

## Failure Boundary
Do not auto-switch fallback, do not expose tokens, and do not absorb SG06 orchestration.

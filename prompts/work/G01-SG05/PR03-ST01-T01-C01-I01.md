## Goal
Prove primary legacy-independence and explicit fallback reachability with deterministic regression evidence.

## Output contract
Tests/evidence showing both:

### Primary side
- no profile directory or `cookies.json` is required to enter/execute the primary SG04 path;
- primary startup does not call `review_profiles`, `repair_regions`, `add_new_regions`, `warm_region`, `browser_fetch_prices` or `get_wb_dest`;
- primary Ozon failure remains explicit failure rather than launching browser;
- missing `wb_dest` remains valid for SG03 primary WB.

### Legacy side
- explicit legacy/fallback selection reaches preserved legacy Ozon profile/cookie/browser capability;
- explicit legacy maintenance selection reaches preserved warm/profile/dest tools;
- existing legacy config/profile artifacts are still consumable.

## Acceptance
Tests fail on accidental recoupling or deletion. Where a visible browser cannot run in CI/headless environment, deterministic entrypoint tests plus a documented desktop smoke command/procedure are required; lack of desktop runtime on CI is not permission to delete the capability.

## Failure conditions
If the only way to test fallback is to put it back into primary flow, return `STRUCTURAL_REPAIR_REQUIRED`.

## Scope
Regression/evidence only. No new automatic fallback policy, persistence, scheduler or marketplace semantics.

## Goal
Preserve the interactive legacy regional setup/support tools behind an explicit operator-maintenance entrypoint while removing them from normal primary startup.

## Output contract
Intentional legacy support capability preserving:
- profile review/repair/add-region workflow where still useful for legacy mode;
- `warm_region` for manual Ozon profile/cookies preparation;
- `get_wb_dest` for optional manual WB dest discovery;
- existing legacy configuration compatibility needed by fallback.

## Acceptance
Primary proxy-first collection does not run these tools automatically; missing `wb_dest` remains valid primary input; manual dest discovery is optional support only; useful legacy maintenance remains reachable; no extra mandatory CityRecord fields.

## Evidence
CLI/entrypoint invocation tests proving explicit selection + primary no-call spies; regression around no-dest primary contract.

## Failure conditions
Legacy setup runs before every primary run, or manual dest/cookies become primary prerequisite -> `PRIMARY_LEGACY_RECOUPLED`.

## Scope
Legacy support entrypoints only. No automatic fallback policy, price/stock parsing, persistence or scheduler.

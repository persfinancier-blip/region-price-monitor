# G01.SG02.PR01.ST01.T01.C02.I01

## Supersedes
`G01.SG02.PR01.ST01.T01.C01.I01` only for the runtime ambiguity discovered during Wave 2. C01 remains immutable history.

## Finding
Operator evidence used an ASocks endpoint configured as HTTPS on port 443, while a scheme-less `host:port` value was normalized by ProxyContext using the documented legacy HTTP default. Native curl then sent plaintext HTTP CONNECT to the proxy port and received nginx HTTP 400 before marketplace semantics.

## Goal
Preserve the minimum CityRecord while removing protocol guessing from live/production evidence paths.

## Required result
1. `proxy` remains the only routing field; no new CityRecord field is introduced.
2. Explicit `http://`, `https://`, `socks4://`, `socks5://`, `socks5h://` values remain preserved.
3. Legacy `host:port` support remains available with the documented HTTP default for compatibility.
4. Callers that require trustworthy live routing can demand an explicit proxy scheme and fail closed on scheme-less input.
5. Wave 2 live probe must require `scheme://host:port` and must not silently choose HTTP.
6. Safe identity and secret redaction remain unchanged.

## Acceptance
- explicit HTTPS proxy remains HTTPS through requests/curl/browser projection;
- strict mode rejects scheme-less proxy before any network call;
- legacy non-strict host:port behavior remains covered;
- no credential exposure and no marketplace semantic changes.

## Failure boundary
Do not infer protocol from port number. Do not add a mandatory CityRecord field. Do not change WB/Ozon semantics.

# G01.SG02.PR02.ST01.T01.C01.I01

## Goal
Implement the `requests` transport adapter using the accepted ProxyContext and common TransportOutcome contract.

## Inputs
- accepted G01.SG02.PR01 outputs;
- current `parser/core/wb.py` request shape;
- `docs/development/G01/SG02/vertical.md`.

## Required result
A narrow adapter that:
1. applies the authenticated proxy endpoint to both HTTP/HTTPS when ProxyContext is supplied;
2. executes caller-specified request metadata needed by WB without owning WB parsing;
3. never silently retries direct/no-proxy after proxy failure;
4. maps proxy/connect/timeout/HTTP/unexpected outcomes to the common safe contract;
5. never prints raw exception text that can contain credentials.

## Tests/evidence
Mock/spy on the underlying `requests` call and prove the proxy mapping used by the call came from ProxyContext. Add explicit failure-classification tests and a no-direct-fallback regression.

## Write boundary
Adapter/tests and the minimum shared transport contract only. Do not implement WB stock, optional-dest behavior, Ozon transport, persistence, scheduler or browser fallback.

## Stop/fail condition
A proxy-supplied call that can fall back to direct networking is blocking failure.

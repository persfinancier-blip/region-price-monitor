# G01.SG02.PR01.ST02.T01.C01.I01

## Goal
Define one safe structured transport outcome/error contract for both marketplace HTTP stacks.

## Inputs
- accepted output of G01.SG02.PR01.ST01.T01;
- current WB/Ozon failure behavior as regression evidence;
- `docs/development/G01/SG02/vertical.md`.

## Required result
A source-neutral transport outcome model that preserves enough facts for collectors to distinguish:
- successful HTTP response;
- proxy authentication/proxy connection failure;
- timeout;
- other connection/DNS/TLS transport failure where distinguishable;
- HTTP non-success response;
- unexpected adapter failure.

The model must never use `[]`, `{}`, zero price/stock, or another valid-looking marketplace value to represent transport failure. Safe messages must redact credentials/authenticated proxy URLs.

## Tests/evidence
Deterministic mapping tests for representative exceptions/statuses, including secret-bearing dummy exception text. Prove redaction.

## Write boundary
Transport contract/tests only. No marketplace price/stock parsing, Ozon cookie/session bootstrap, WB dest semantics, DB/persistence or scheduler changes.

## Stop/fail condition
If a library-specific detail cannot fit the common result without losing information needed by later SGs, expose a bounded adapter-detail field rather than creating marketplace semantics in transport.

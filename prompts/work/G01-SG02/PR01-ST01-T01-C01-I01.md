# G01.SG02.PR01.ST01.T01.C01.I01

## Goal
Implement the minimum authenticated `ProxyContext` derived only from the accepted SG01 CityRecord proxy fields.

## Canonical inputs
- Issue #32;
- `docs/development/G01/SG02/vertical.md`;
- SG01 CityRecord contract;
- current `parser/core/wb.py`, `parser/core/ozon.py` only as transport-consumer evidence.

## Required result
A small transport-layer representation that:
1. accepts `city`, `proxy`, `proxy_user`, `proxy_password` (`wb_dest` irrelevant);
2. accepts `host:port` and applies a documented default proxy scheme compatible with current HTTP proxy usage;
3. preserves an already-supported explicit proxy scheme;
4. safely URL-encodes username/password for adapter use;
5. exposes a safe diagnostic identity that never contains password/raw authenticated URI;
6. rejects malformed/empty proxy data explicitly;
7. adds no new mandatory user field.

## Tests/evidence
Use dummy credentials, including `@`, `:`, `/`, `%` and spaces. Prove deterministic endpoint construction and redacted representation. No live paid proxy is required for this Task.

## Write boundary
Minimum new transport module/tests. Do not modify marketplace parsing, DB schemas, result persistence, scheduler, browser fallback, Ozon cookie/session semantics or WB dest behavior.

## Stop/fail condition
If the agreed minimum CityRecord cannot construct a usable proxy endpoint without another mandatory user field, STOP and report `CITY_PROXY_CONTRACT_INSUFFICIENT`; do not silently widen the contract.

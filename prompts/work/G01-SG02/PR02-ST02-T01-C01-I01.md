# G01.SG02.PR02.ST02.T01.C01.I01

## Goal
Implement the `curl_cffi` transport adapter using the accepted ProxyContext and common TransportOutcome contract.

## Inputs
- accepted G01.SG02.PR01 outputs;
- current `parser/core/ozon.py` curl_cffi/session usage;
- `docs/development/G01/SG02/vertical.md`.

## Required result
A narrow adapter that:
1. consumes the same ProxyContext as the requests adapter;
2. applies authenticated proxy settings to every network call made through the adapter, including caller-owned session/bootstrap calls;
3. preserves caller-specified impersonation/session/cookies as opaque request inputs but does not require a profile/cookies file itself;
4. never silently retries direct/no-proxy after proxy failure;
5. maps failures to the common safe outcome and does not print raw secret-bearing exception text.

## Tests/evidence
Mock direct and Session call paths, assert proxies on each underlying call, prove no-profile construction/use, error mapping, redaction, and no-direct-fallback.

## Write boundary
Adapter/tests only. Do not remove Ozon cookies from the current collector, invent regional bootstrap, parse price differently, or modify WB/persistence/scheduler/fallback.

## Stop/fail condition
If a required curl_cffi call cannot be forced through ProxyContext, STOP with exact call-path evidence; do not leave an unproxied bootstrap request.

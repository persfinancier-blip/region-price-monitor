# G01.SG02.PR03.ST01.T01.C01.I01

## Goal
Bind the existing WB and Ozon network call boundaries to the accepted shared proxy transport without taking ownership of marketplace semantics.

## Inputs
- accepted PR01/PR02 outputs;
- current `parser/core/wb.py` and `parser/core/ozon.py`;
- SG01 CityRecord/CitySet contract;
- `docs/development/G01/SG02/vertical.md`.

## Required result
1. both collector modules consume a city-bound ProxyContext/shared transport rather than independently inventing proxy mappings;
2. every WB underlying request uses the requests adapter;
3. every Ozon underlying request, including its current homepage warm call and product call, uses the curl_cffi adapter/context;
4. when ProxyContext is supplied there is no direct-network fallback;
5. existing WB price parsing and Ozon cookie/price behavior remain semantically unchanged except for transport failure becoming explicit;
6. this Task does not claim optional-WB-dest support, WB stock, or cookie-free Ozon regional operation.

## Tests/evidence
Collector-boundary spies proving the same city proxy context reaches every network call. Regression test that transport failure is surfaced distinctly from successful empty/no-price semantic data.

## Write boundary
Narrow edits to network call integration in `wb.py`/`ozon.py`, shared transport code and tests. No DB/result schema/scheduler/browser fallback changes; no SG03/SG04 semantic implementation.

## Stop/fail condition
If correct integration requires changing marketplace semantics owned by SG03/SG04, stop with an interface finding instead of widening this Task.

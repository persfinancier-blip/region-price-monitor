# G01.SG06.PR03.ST03.T01.C01.I01

## Role
Implement/prove only repeated-run identity and resource lifecycle for the non-interactive primary runner.

## Goal
Show that two sequential configured runs are independent, repeatable and require no human regional maintenance.

## Inputs
- accepted PR03 non-interactive runner;
- same configured ProductSet/CitySet source data for two sequential executions;
- accepted SG04 context/browser lifecycle contract.

## Actions
1. Execute/fixture two sequential runs with the same configured inputs.
2. Prove each run obtains a distinct run_id and independent timestamps.
3. Prove prior persisted rows remain associated with their original run_id.
4. Prove SG04 context/session/browser resources are reused only where SG04 explicitly permits and never under a different city identity.
5. Prove hidden browser/driver resources are bounded and cleaned after their intended lifetime.
6. Prove expired/rejected primary state yields typed primary failure and never silently enters SG05.
7. Prove second run requires no interactive city/PVZ/profile/cookie maintenance.

## Output Contract
Repeat-run lifecycle evidence and any typed lifecycle failure finding.

## Acceptance
- distinct run identities;
- no cross-run overwrite/mutation;
- no cross-city context reuse;
- resource cleanup deterministic;
- no human regional work between runs;
- no automatic legacy fallback.

## Evidence
Two-run integration fixture/spies covering successful reuse where allowed, forced context expiry/rebootstrap, browser cleanup, persistence separation and no-stdin behavior.

## Failure Boundary
Do not redesign SG04 engine selection, create scheduler services, alter persistence schema beyond what PR02 owns, or change SG05 fallback semantics.

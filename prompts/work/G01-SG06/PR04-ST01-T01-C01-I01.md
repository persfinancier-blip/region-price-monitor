# G01.SG06.PR04.ST01.T01.C01.I01

## Role
Execute only the deterministic end-to-end SG06 mixed-outcome acceptance fixture and persistence parity proof.

## Goal
Prove that the planned matrix, terminal accounted outcomes, file rows and PostgreSQL rows all represent the same complete run semantics under mixed success/failure conditions.

## Inputs
Accepted PR01–PR03 interfaces and a deterministic fixture with:
- at least two cities;
- WB and Ozon products;
- WB positive stock success;
- WB zero-stock success;
- at least one transport/proxy failure;
- at least one marketplace context/parser semantic failure;
- both file and PostgreSQL outputs enabled where test environment supports PG.

## Actions
1. Compute expected RunPlan count before execution.
2. Execute the controlled mixed-outcome run through the SG06 orchestration boundary.
3. Assert terminal accounted count equals planned count.
4. Assert failure of one unit does not remove unrelated successes/failures.
5. Reload canonical file output and compare exact required semantic keys/fields to RunResultSet.
6. Reload PostgreSQL rows by run_id and compare required semantic keys/fields to RunResultSet.
7. Assert WB stock quantity/availability and explicit error status survive both targets.
8. Assert no secret material appears in persisted outputs/evidence.

## Output Contract
One acceptance evidence bundle containing planned count, terminal count, file count, PG count, semantic parity assertions and failure-isolation proof.

## Acceptance
- no success-only filtering;
- no silent missing/duplicate unit;
- file and PG required-field semantics equal canonical RunResultSet;
- zero stock remains valid zero stock;
- failures remain explicit rows;
- if live PG is unavailable, do not fake DB acceptance: emit a clear PostgreSQL integration-evidence prerequisite while deterministic schema tests may still run.

## Failure Boundary
Do not change implementation to force fixture PASS inside this Task; findings route back to the owning PR01/PR02/PR03 Task or structural repair.

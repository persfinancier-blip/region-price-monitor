# G01.SG06.PR01.ST01.T01.C01.I01

## Role
Implement only deterministic RunPlan construction for the primary parser run. Do not execute marketplace requests or persistence.

## Goal
Materialize the complete expected semantic matrix before collection so downstream code can prove that no requested unit disappeared.

## Inputs
- accepted SG01 ProductSet;
- accepted SG01 CitySet;
- configured enabled marketplaces;
- parent SG06 contract `docs/development/G01/SG06/vertical.md`.

## Actions
1. Define a stable planned-unit semantic key `(marketplace, sku, city)`.
2. Allocate one `run_id` for the execution before network work starts.
3. Expand every enabled marketplace's products across every selected city.
4. Produce deterministic total and per-marketplace expected counts.
5. Handle exact duplicate semantic input keys explicitly and deterministically; never silently multiply them or silently choose inconsistent behavior.
6. Keep plan construction independent of `wb_dest`, Ozon profile/cookies, network availability and output target.

## Output Contract
Immutable/inspectable `RunPlan` containing `run_id`, planned keys and expected counts, or explicit plan/input failure.

## Acceptance
- WB products produce only WB units; Ozon products produce only Ozon units;
- all cities participate for each applicable product;
- no network calls;
- no legacy profile/cookie/dest prerequisite;
- no planned key lacks marketplace/SKU/city identity;
- duplicate-key policy is test-covered and never causes silent cardinality drift.

## Evidence
Deterministic fixtures with multiple cities/marketplaces/products, empty-source negatives and duplicate-key fixtures.

## Failure Boundary
Do not call collectors, build ProxyContext, parse marketplace data, persist rows, implement scheduler/fallback, or widen SG01 input contracts.

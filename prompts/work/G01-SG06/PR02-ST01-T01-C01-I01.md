# G01.SG06.PR02.ST01.T01.C01.I01

## Role
Implement only canonical RunResult normalization from reconciled SG03/SG04 outcomes. No storage or orchestration redesign.

## Goal
Produce one persistence-safe common row contract that preserves marketplace identity, success/failure semantics and WB stock without inventing values.

## Inputs
- accepted PR01 reconciled outcome set;
- SG03 normalized WB outcome contract;
- SG04 normalized Ozon outcome contract.

## Actions
1. Define common required fields: `run_id`, `timestamp`, `marketplace`, `sku`, `city`, `price`, `status`, `error_code`, `error`, `source`.
2. Define WB-specific nullable fields `stock_qty`, `is_available`.
3. Preserve useful existing price variants as optional fields if already produced.
4. Map every accepted success/failure into this contract without changing marketplace semantics.
5. Ensure failures have nullable business values rather than invented zero/true defaults.
6. Redact unsafe raw exception/credential material before it becomes result-shaped data.

## Output Contract
Canonical `RunResult` rows, one for each reconciled planned unit.

## Acceptance
- zero stock remains distinct from failure;
- failed Ozon/WB unit preserves sku/city/status/error;
- `price=None` on failure is valid and not coerced to zero;
- `is_available` is not defaulted true for failed/unknown rows;
- no proxy credentials or SG05 personalized cookie/token material in results;
- row count unchanged from reconciled planned count.

## Evidence
Normalization fixtures for WB success positive/zero stock, Ozon success, transport/context/parser/accounting failures and secret-like exception redaction.

## Failure Boundary
Do not create DB tables, write CSV, call collectors, choose sources, launch browsers or change SG03/SG04 semantics.

# G01.SG06.PR03.ST01.T01.C01.I01

## Role
Implement only primary collector orchestration against an accepted RunPlan. Do not persist results or invoke legacy fallback.

## Goal
Execute SG03/SG04 through the correct city ProxyContext and preserve per-planned-unit isolation even when a batch/city/collector fails.

## Inputs
- accepted RunPlan;
- SG01 CitySet;
- SG02 ProxyContext construction/transport;
- accepted SG03 WB collector interface;
- accepted SG04 Ozon collector/context interface.

## Actions
1. Resolve each planned city's exact CityRecord and construct/use its SG02 ProxyContext.
2. Dispatch WB planned units through SG03; batching is allowed internally only if outcomes remain attributable per planned key.
3. Dispatch Ozon planned units through SG04; hidden/headless browser is allowed only under SG04 C02 contract and remains city-bound.
4. Catch failures at the narrowest safe scope and emit/route typed failures for affected planned units rather than aborting unaccounted siblings.
5. Preserve partial collector outcomes for PR01 reconciliation.
6. Remove/avoid `_enrich()`-style filtering that drops `error` outcomes.
7. Never automatically invoke SG05 legacy profile/cookies/browser fallback.

## Output Contract
Raw typed SG03/SG04 outcomes plus explicit orchestration failures sufficient for PR01 reconciliation against the full RunPlan.

## Acceptance
- every attempted network path is city ProxyContext-bound;
- one city/marketplace failure does not erase unrelated units;
- WB no-dest cities are still attempted through SG03 contract;
- Ozon primary has no personalized SG05 auth-cookie prerequisite;
- no result failure is discarded because it has an `error` field;
- no direct fallback or automatic legacy invocation.

## Evidence
Mocked/integration orchestration fixtures with city A success, city B proxy failure, WB batch partial result, Ozon context failure and sibling continuation.

## Failure Boundary
Do not alter SG03 stock schema, SG04 engine/city verification rules, RunResult persistence, interactive legacy tools or scheduler service.

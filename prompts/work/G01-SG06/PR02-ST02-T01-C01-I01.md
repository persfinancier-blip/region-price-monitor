# G01.SG06.PR02.ST02.T01.C01.I01

## Role
Implement only complete file persistence for canonical RunResultSet.

## Goal
Persist one run-level representation from which every planned unit—including failures—can be recovered without consulting logs.

## Inputs
- complete canonical RunResultSet from PR02.ST01;
- configured file output directory/path.

## Actions
1. Write a canonical run-scoped CSV (or equally simple existing-supported flat representation if repository evidence justifies it) containing every RunResult row.
2. Include required common fields and WB stock/availability fields.
3. Preserve identical run_id on all rows.
4. Never filter rows by success, price presence or marketplace.
5. Make file naming/run identity collision-safe across repeated executions.
6. Existing legacy per-region/per-marketplace CSV outputs may remain for compatibility but cannot replace the complete canonical run artifact.

## Output Contract
Path/metadata for a complete durable file representation of one RunResultSet, or explicit persistence failure.

## Acceptance
- written row count equals RunPlan count;
- failure rows present;
- city/SKU/status/error present;
- WB stock/availability survives;
- no secret-bearing fields are serialized;
- repeated runs do not overwrite one another unintentionally.

## Evidence
Temp-directory tests that reload the file and compare required semantic fields/row keys to the canonical RunResultSet, including mixed failures and zero stock.

## Failure Boundary
Do not alter PostgreSQL, collectors, RunPlan semantics, scheduler behavior or SG05 fallback.

# G01.SG03.PR01-ST01-T01.C06.I01

## Goal
Before any endpoint/price/stock work, prove that the real Wildberries product page is visibly usable in a normal Chrome window through the accepted SG02 ProxyContext.

## Scope
- control product page only: `https://www.wildberries.ru/catalog/<sku>/detail.aspx`;
- visible/non-headless browser;
- same SG02 ProxyContext only;
- neutral browser egress proof before marketplace navigation;
- no WB API endpoint discovery, no price parsing, no stock parsing in this cycle.

## Acceptance
Browser visibly opens the requested WB product page through the proxy. Operator can inspect it. SAFE REPORT records only bounded navigation metadata and browser egress identity, no page data/secrets.

## Failure
Browser startup/proxy-binding/navigation failure is explicit. Do not continue into WB data endpoints until the owner supplies/approves the required endpoint work.

# G01.SG03.PR01.ST01.T01.C07.I01

## Goal
Prove that the future server runtime can reach the real Wildberries website through SG02 ProxyContext without Chrome, Selenium, Playwright or user interaction.

## Input Contract
- explicit-scheme ProxyContext with city-bound proxy credentials;
- control WB SKU;
- official WB product page only: `https://www.wildberries.ru/catalog/<sku>/detail.aspx`.

## Actions
1. Confirm the Requests stack egress through `https://api.i.pn/json/`.
2. Request the official WB product page through the SG02 Requests adapter.
3. Record bounded HTTP response evidence only: status, content type/server headers, title when present, body length/hash, local Git-ignored body path.
4. Do not call WB data endpoints and do not parse price/stock.

## Acceptance
`WB_SITE_REACHABLE` when the server Requests stack receives an HTTP response from the requested HTTPS WB host through the confirmed ProxyContext. A non-2xx marketplace response still proves reachability but does not prove data access.

## Failure
No HTTP response / proxy or connection failure -> `WB_SITE_UNREACHABLE`.

## Boundary
No browser dependency, no user interaction, no endpoint guessing, no price/stock semantics.

# Immutable Prompt — G01.SG03.PR03.ST01.T01.C01.I01

## Task
Implement WB response parsing for regional price plus endpoint-evidenced stock/availability using only the accepted PR01 normalization contract.

## Authority
Parent Task: `G01.SG03.PR03.ST01.T01`.
Prerequisite: accepted `G01.SG03.PR01.ST02.T01` normalization contract.
Contract: `docs/development/G01/SG03/vertical.md`.

## Inputs
- sanitized accepted WB response fixtures;
- exact stock/price normalization rules;
- existing `parser/core/wb.py` price parser behavior.

## Actions
1. Parse product identity and current price/base price from the evidenced response shape.
2. Parse stock quantity/availability from the exact evidenced paths.
3. Apply the accepted multi-size/multi-stock aggregation rule if one exists.
4. Return normalized per-product semantic data without transport concerns.
5. Preserve zero stock as `stock_qty=0` and availability false according to accepted stock semantics.
6. Never infer stock/availability from price presence or price amount.
7. Detect unsupported/malformed response structures explicitly for the classifier Task.

## Acceptance
Fixtures prove at minimum positive stock, zero/unavailable, supported multi-entry case when applicable, and malformed/unsupported shape. Parsed `sku`, price and stock fields are deterministic.

## Forbidden scope
No network calls, optional-dest request logic, collector loop, persistence, Ozon, scheduler or fallback changes.

## Stop condition
All accepted PR01 fixtures normalize to the exact expected WB semantic values without stock-from-price inference.

# Immutable Prompt — G01.SG03.PR02.ST01.T01.C01.I01

## Task
Implement the WB detail-request construction boundary so `wb_dest` is truly optional and every primary request uses the accepted SG02 ProxyContext.

## Authority
Parent Task: `G01.SG03.PR02.ST01.T01`.
Subgoal: Issue #33.
Contract: `docs/development/G01/SG03/vertical.md`.
Accepted prerequisite when executed: SG02 transport tasks.

## Inputs
- current `parser/core/wb.py`;
- canonical CityRecord;
- SG02 ProxyContext / requests adapter;
- WB SKU batch.

## Actions
1. Replace the current mandatory positional-dest request assumption with an explicit request builder/specification.
2. Always include existing required WB parameters such as app/currency/SKU batch that remain valid under current contract.
3. If `wb_dest` is present, include `dest` with that exact value.
4. If `wb_dest` is absent/blank/None, omit `dest` entirely; do not send zero, empty string, synthetic default or guessed region ID.
5. Route the request through SG02 requests transport using the city ProxyContext.
6. Preserve typed SG02 transport outcomes instead of converting failures to `[]`.
7. Keep a narrowly bounded legacy-compatible call path only if required for SG05 preservation, but primary CityRecord execution must not bypass SG02.

## Acceptance
- request-spy test proves exact params with dest;
- request-spy test proves exact absence of `dest` without it;
- ProxyContext is used in both cases;
- no silent direct fallback;
- missing dest does not invoke `warm_browser.get_wb_dest`, abort or skip;
- no stock parsing is implemented here.

## Forbidden scope
No WB stock-field interpretation, Ozon, persistence, scheduler or legacy browser redesign.

## Stop condition
Both optional-dest request forms deterministically reach SG02 transport and produce a typed transport outcome.

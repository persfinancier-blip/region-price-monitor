# Immutable Prompt — G01.SG03.PR01.ST02.T01.C01.I01

## Task
Define the canonical WB price/stock normalization contract strictly from accepted current-endpoint evidence.

## Authority
Parent Task: `G01.SG03.PR01.ST02.T01`.
Prerequisite: accepted output of `G01.SG03.PR01.ST01.T01`.
Contract: `docs/development/G01/SG03/vertical.md`.

## Inputs
- sanitized current WB fixtures/schema;
- current `parser/core/wb.py` price behavior;
- SG03 output contract.

## Actions
1. Map evidenced response fields to normalized WB observation fields.
2. Define exactly how `price`, `price_base`, `stock_qty` and `is_available` are obtained.
3. If response contains multiple sizes/stock entries, define one deterministic aggregation rule justified by the endpoint evidence and the Goal's question: availability/stock for the requested product in that regional request context.
4. Define explicit semantic states for positive stock, zero stock, product absent, expected structure absent/malformed and any evidenced unavailable state.
5. Preserve the distinction between semantic response states and SG02 transport failures.

## Required output
A tested normalization contract consumable by the parser Task, including fixture-to-expected-output cases.

## Acceptance
- every normalized field has an evidenced source path;
- `is_available` is derived from evidenced stock semantics, never from `price > 0`;
- `stock_qty=0` is valid data and not an error;
- aggregation across sizes/stocks is deterministic and documented only if required by evidence;
- malformed/unsupported endpoint shape fails explicitly.

## Failure
If evidence is insufficient to define any required stock field or aggregation rule, stop with `WB_STOCK_CONTRACT_UNPROVEN`; do not widen the Prompt or invent assumptions.

## Forbidden scope
No networking implementation, optional-dest request changes, collector integration, persistence, Ozon or fallback work.

## Stop condition
One exact WBObservation normalization contract exists and all fixture expectations are internally consistent.

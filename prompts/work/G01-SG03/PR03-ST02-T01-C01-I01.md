# Immutable Prompt — G01.SG03.PR03.ST02.T01.C01.I01

## Task
Define and implement typed WB semantic outcome classification so valid zero stock, product absence, malformed response and SG02 transport failures remain distinct.

## Authority
Parent Task: `G01.SG03.PR03.ST02.T01`.
Prerequisites: accepted SG02 TransportOutcome and SG03 PR03.ST01 parser.
Contract: `docs/development/G01/SG03/vertical.md`.

## Inputs
- per-product parser outputs/errors;
- SG02 transport outcomes;
- requested SKU batch identity.

## Actions
1. For every requested SKU, classify one outcome:
   - success with price/stock data;
   - valid zero-stock/unavailable semantic result;
   - product-not-present/not-found semantic failure;
   - malformed/unsupported WB response;
   - typed SG02 proxy/auth/connect/timeout/HTTP failure;
   - unexpected parser failure.
2. Preserve requested SKU identity even when WB omits a product from the returned product array.
3. Eliminate the current universal `[]` failure behavior from the primary typed path.
4. Keep diagnostic text secret-free.

## Acceptance
- zero stock cannot be mistaken for transport failure;
- missing requested SKU produces an explicit SKU-scoped outcome;
- one malformed/missing SKU does not erase sibling SKU results;
- SG02 typed failures remain transport failures rather than WB data;
- no valid-looking zero/empty data substitutes for failure.

## Forbidden scope
No DB/storage changes, scheduler, Ozon or legacy fallback redesign.

## Stop condition
Each requested SKU has one deterministic semantic/transport outcome classification consumable by the WB collector.
